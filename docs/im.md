# Instant messages

## Установка

Сообщения вынесены в отдельный репозиторий. Это микросервис, написанный на Go, к нему обращаются api-методы.

За подключение к сообщениям отвечает ветка в `openvk.yml` `credentials.im`:

`enable`,
`server_url` - URL микросервиса
`lp_server_addr` - URL LongPoll-подключения

За подключение к микросервису отвечает IMBroker.

Запустить микросервис:
`go run .`

(для запуска требуется redis)

Создать или пересоздать базу данных:
`go run . db create`

Переместить старые данные:
`go run . db migrate-legacy`

## Функции

### Чаты

#### Привязка к группе

Чат можно привязать к группе. В ВК эта связь является отдельной сущностью, но, для упрощения, здесь сделано именно так, чтобы чат привязывался к Topic.
Чат может быть привязан только к одной такой теме. По умолчанию тема принимает название чата, но можно задать и своё, если просто поменять его. Чтобы вернуть название чата, в названии темы напишите "-".
