# Объект Doc

Объект **Doc** описывает документ (файл) ВКонтакте / OpenVK. Структура возвращаемых полей зависит от версии API, переданной в параметре `v`.

---

## Версия API 5.0 и выше (v >= 5.0)

В версиях API 5.0+ используются следующие поля:

| Поле | Тип | Описание |
| --- | --- | --- |
| `id` | integer | Идентификатор документа. |
| `owner_id` | integer | Идентификатор владельца документа. |
| `title` | string | Название документа с расширением. |
| `size` | integer | Размер файла в байтах. |
| `ext` | string | Расширение файла (например `"pdf"`, `"png"`, `"zip"`). |
| `url` | string | Прямая ссылка для скачивания файла. |
| `date` | integer | Дата добавления документа (Unix timestamp). |
| `type` | integer | Тип документа (`1` — текст, `2` — архив, `3` — GIF, `4` — изображение, `5` — аудио, `6` — видео, `7` — электронная книга, `8` — неизвестно). |
| `access_key` | string | Ключ доступа к документу. |
| `preview` | object | *(Опционально)* Объект с миниатюрами предварительного просмотра (`photo`, `sizes`). |
| `tags` | array | *(Опционально)* Теги документа. |

### Пример объекта (v >= 5.0)
```json
{
    "id": 12,
    "owner_id": 1,
    "title": "guide.pdf",
    "size": 1048576,
    "ext": "pdf",
    "url": "https://openvk.instance/docs/1_12.pdf",
    "date": 1696680000,
    "type": 1,
    "access_key": "abc123def456"
}
```

---

## До версии API 5.0 (v < 5.0)

В версиях API 3.x и 4.x возвращается поле `did`:

| Поле | Тип | Описание |
| --- | --- | --- |
| `did` / `id` | integer | Идентификатор документа. |
| `owner_id` | integer | Идентификатор владельца. |
| `title` | string | Название файла. |
| `size` | integer | Размер файла в байтах. |
| `ext` | string | Расширение файла. |
| `url` | string | Ссылка на файл. |
| `date` | integer | Дата добавления (Unix timestamp). |

### Пример объекта (v < 5.0)
```json
{
    "did": 12,
    "owner_id": 1,
    "title": "guide.pdf",
    "size": 1048576,
    "ext": "pdf",
    "url": "https://openvk.instance/docs/1_12.pdf",
    "date": 1696680000
}
```
