# Объект Note

Объект **Note** описывает текстовую заметку пользователя ВКонтакте / OpenVK. Структура возвращаемых полей зависит от версии API, переданной в параметре `v`.

---

## Версия API 5.0 и выше (v >= 5.0)

В версиях API 5.0+ используются следующие поля:

| Поле | Тип | Описание |
| --- | --- | --- |
| `id` | integer | Идентификатор заметки. |
| `owner_id` | integer | Идентификатор владельца (автора) заметки. |
| `title` | string | Заголовок заметки. |
| `text` | string | Полный текст заметки (в формате HTML / Markdown). |
| `date` | integer | Время создания заметки (Unix timestamp). |
| `comments` | integer | Количество комментариев к заметке. |
| `view_url` | string | Относительный или абсолютный URL для просмотра заметки на сайте. |

### Пример объекта (v >= 5.0)
```json
{
    "id": 1,
    "owner_id": 1,
    "title": "Моя первая заметка",
    "text": "Текст интересной заметки в OpenVK",
    "date": 1696680000,
    "comments": 3,
    "view_url": "/note1_1"
}
```

---

## До версии API 5.0 (v < 5.0)

В версиях API 3.x и 4.x возвращается поле `nid`:

| Поле | Тип | Описание |
| --- | --- | --- |
| `nid` / `id` | integer | Идентификатор заметки. |
| `owner_id` | integer | Идентификатор владельца. |
| `title` | string | Заголовок заметки. |
| `text` | string | Текст заметки. |
| `date` | integer | Время создания (Unix timestamp). |
| `comments` | integer | Количество комментариев. |

### Пример объекта (v < 5.0)
```json
{
    "nid": 1,
    "owner_id": 1,
    "title": "Моя первая заметка",
    "text": "Текст интересной заметки в OpenVK",
    "date": 1696680000,
    "comments": 3
}
```
