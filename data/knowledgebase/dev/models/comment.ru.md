# Объект Comment

Объект **Comment** описывает комментарий к записи на стене, фотографии, видеозаписи, теме обсуждения или заметке. Структура возвращаемых полей зависит от версии API, переданной в параметре `v`.

---

## Версия API 5.0 и выше (v >= 5.0)

В современных версиях API используются следующие поля:

| Поле | Тип | Описание |
| --- | --- | --- |
| `id` | integer | Идентификатор комментария. |
| `from_id` | integer | Идентификатор автора комментария. |
| `date` | integer | Время добавления комментария (Unix timestamp). |
| `text` | string | Текст комментария. |
| `reply_to_user` | integer | *(Опционально)* Идентификатор пользователя, в ответ которому оставлен комментарий. |
| `reply_to_comment` | integer | *(Опционально)* Идентификатор комментария, в ответ на который оставлен текущий. |
| `attachments` | array | Список медиа-вложений (фотографии, аудио, документы и др.). |
| `parents_stack` | array | Массив идентификаторов родительских комментариев ветки. |
| `likes` | object | *(Опционально)* Информация об отметках Мне нравится (`count`, `user_likes`, `can_like`). |

### Пример объекта (v >= 5.0)
```json
{
    "id": 10,
    "from_id": 1,
    "date": 1696680000,
    "text": "Отличное обновление!",
    "reply_to_comment": 5,
    "reply_to_user": 2,
    "attachments": [],
    "parents_stack": [5]
}
```

---

## До версии API 5.0 (v < 5.0)

В версиях API 3.x и 4.x возвращаются устаревшие поля `cid` и `uid`:

| Поле | Тип | Описание |
| --- | --- | --- |
| `cid` | integer | Идентификатор комментария (эквивалент `id` в API v5.0+). |
| `uid` | integer | Идентификатор автора (эквивалент `from_id`). |
| `date` | integer | Время добавления комментария (Unix timestamp). |
| `message` / `text` | string | Текст комментария. |
| `reply_to_cid` | integer | *(Опционально)* Идентификатор родительского комментария. |
| `reply_to_uid` | integer | *(Опционально)* Идентификатор адресата ответа. |
| `attachments` | array | Вложения (в API v < 4.0 фото вкладываются напрямую в массив). |

### Пример объекта (v < 5.0)
```json
{
    "cid": 10,
    "uid": 1,
    "date": 1696680000,
    "text": "Отличное обновление!",
    "reply_to_cid": 5
}
```
