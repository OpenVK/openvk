# Объект Poll

Объект **Poll** описывает опрос (голосование) в записи на стене или сообщении. Структура возвращаемых полей зависит от версии API, переданной в параметре `v`.

---

## Версия API 5.0 и выше (v >= 5.0)

В версиях API 5.0+ используются следующие поля:

| Поле | Тип | Описание |
| --- | --- | --- |
| `id` | integer | Идентификатор опроса. |
| `owner_id` | integer | Идентификатор владельца опроса. |
| `question` | string | Текст вопроса опроса. |
| `votes` | integer | Общее количество проголосовавших пользователей. |
| `answers` | array | Массив объектов вариантов ответа (`id`, `text`, `votes`, `rate`). |
| `anonymous` | boolean | Является ли опрос анонимным. |
| `multiple` | boolean | Разрешен ли выбор нескольких вариантов ответа. |
| `end_date` | integer | Дата завершения опроса (Unix timestamp) или `0`, если опрос бессрочный. |
| `closed` | boolean | Завершен ли опрос. |
| `can_vote` | boolean | Может ли текущий пользователь проголосовать в опросе. |
| `can_share` | boolean | Разрешено ли делиться опросом. |
| `answer_ids` | array | Массив идентификаторов ответов, выбранных текущим пользователем. |
| `disable_unvote` | boolean | Запрещено ли отменять/изменять свой голос. |

### Структура объекта ответа (`answers[]`)
| Поле | Тип | Описание |
| --- | --- | --- |
| `id` | integer | Идентификатор варианта ответа. |
| `text` | string | Текст варианта ответа. |
| `votes` | integer | Количество голосов за данный вариант. |
| `rate` | float | Процент голосов от общего числа (от `0.0` до `100.0`). |

### Пример объекта (v >= 5.0)
```json
{
    "id": 1,
    "owner_id": 1,
    "question": "Какой раздел OpenVK вам нравится больше всего?",
    "votes": 42,
    "anonymous": false,
    "multiple": false,
    "end_date": 0,
    "closed": false,
    "can_vote": true,
    "can_share": true,
    "answer_ids": [1],
    "answers": [
        {
            "id": 1,
            "text": "Сообщения",
            "votes": 25,
            "rate": 59.52
        },
        {
            "id": 2,
            "text": "Музыка",
            "votes": 17,
            "rate": 40.48
        }
    ]
}
```

---

## До версии API 5.0 (v < 5.0)

В версиях API 3.x и 4.x возвращается поле `poll_id`:

| Поле | Тип | Описание |
| --- | --- | --- |
| `poll_id` / `id` | integer | Идентификатор опроса. |
| `owner_id` | integer | Идентификатор владельца. |
| `question` | string | Текст вопроса. |
| `votes` | integer | Общее число голосов. |
| `answers` | array | Список вариантов ответа. |
| `answer_id` | integer | Идентификатор выбранного пользователем ответа. |

### Пример объекта (v < 5.0)
```json
{
    "poll_id": 1,
    "owner_id": 1,
    "question": "Какой раздел OpenVK вам нравится больше всего?",
    "votes": 42,
    "answer_id": 1,
    "answers": [
        {
            "id": 1,
            "text": "Сообщения",
            "votes": 25,
            "rate": 59.52
        },
        {
            "id": 2,
            "text": "Музыка",
            "votes": 17,
            "rate": 40.48
        }
    ]
}
```
