# Объект Message

Объект **Message** описывает личное сообщение или сообщение в групповой беседе.

> **Важно:** В версии API **5.80** произошла масштабная реорганизация системы сообщений: адресация переведена на `peer_id` и `conversation_message_id`, поле `body` заменено на `text`, а работа с беседами переведена в модель **[conversation](/dev/models/conversation)**.

---

## Версия API 5.80 и выше (v >= 5.80)

Начиная с версии API 5.80, используется современный унифицированный формат сообщения:

| Поле | Тип | Описание |
| --- | --- | --- |
| `id` | integer | Глобальный уникальный идентификатор сообщения. |
| `conversation_message_id` | integer | Локальный порядковый идентификатор сообщения внутри конкретной беседы/диалога. |
| `date` | integer | Время отправки сообщения (Unix timestamp). |
| `peer_id` | integer | Идентификатор назначения (пользователь `id`, сообщество `-id` или беседа `2000000000 + chat_id`). |
| `from_id` | integer | Идентификатор автора сообщения (пользователя или сообщества). |
| `text` | string | Текст сообщения (экранированный UTF-8). |
| `out` | integer | `1` — исходящее сообщение от текущего пользователя, `0` — входящее. |
| `important` | boolean | Отмечено ли сообщение как важное. |
| `is_hidden` | boolean | Скрыто ли сообщение. |
| `attachments` | array | Список медиа-вложений (фотографии, аудио, видео, документы, стикеры и др.). |
| `fwd_messages` | array | Список пересланных сообщений (массив объектов `Message`). |
| `reply_message` | object\|null | Объект сообщения, на которое был дан ответ (цитирование). |
| `action` | object\|null | Объект сервисного действия в беседе (`type`, `member_id`, `text`). |

### Пример объекта (v >= 5.80)
```json
{
    "id": 1050,
    "conversation_message_id": 42,
    "date": 1696680000,
    "peer_id": 2000000001,
    "from_id": 1,
    "text": "Привет всем разработчикам!",
    "out": 1,
    "important": false,
    "attachments": [],
    "fwd_messages": []
}
```

## Версии API 5.0 — 5.79 (5.0 <= v < 5.80)

В версиях до 5.80 данные беседы и метаинформация чата передавались непосредственно внутри самого объекта сообщения:

| Поле | Тип | Описание |
| --- | --- | --- |
| `id` | integer | Идентификатор сообщения. |
| `user_id` | integer | Идентификатор собеседника (для диалогов один-на-один) или автора. |
| `from_id` | integer | Идентификатор автора сообщения. |
| `date` | integer | Время отправки (Unix timestamp). |
| `read_state` | integer | `1` — прочитано, `0` — не прочитано. |
| `out` | integer | `1` — исходящее, `0` — входящее. |
| `title` | string | Заголовок диалога или название беседы. |
| `body` | string | Текст сообщения. |
| `chat_id` | integer | Идентификатор беседы (номер `1...N` без смещения). |
| `chat_active` | array | Массив идентификаторов участников беседы. |
| `users_count` | integer | Количество участников беседы. |
| `admin_id` | integer | Идентификатор создателя беседы. |
| `photo_50` | string | URL обложки беседы 50x50px. |
| `photo_100` | string | URL обложки беседы 100x100px. |
| `photo_200` | string | URL обложки беседы 200x200px. |
| `action` | string | Тип сервисного действия (`"chat_create"`, `"chat_title_update"`, `"chat_photo_update"`, `"chat_invite_user"`, `"chat_kick_user"`). |
| `action_mid` | integer | Идентификатор целевого пользователя действия. |
| `action_text` | string | Текст действия (новое название беседы и т.д.). |
| `attachments` | array | Список вложений. |
| `fwd_messages` | array | Пересланные сообщения. |
| `emoji` | integer | `1`, если текст содержит эмодзи. |
| `deleted` | integer | `1`, если сообщение удалено. |

### Пример объекта (5.0 <= v < 5.80)
```json
{
    "id": 1050,
    "user_id": 1,
    "from_id": 1,
    "date": 1696680000,
    "read_state": 1,
    "out": 1,
    "title": "Разработчики OpenVK",
    "body": "Привет всем разработчикам!",
    "chat_id": 1,
    "chat_active": [1, 2, 3],
    "users_count": 3,
    "admin_id": 1,
    "attachments": []
}
```

## До версии API 5.0 (v < 5.0)

В ранних версиях протокола (3.x, 4.x) использовались устаревшие имена полей `mid` и `uid`:

| Поле | Тип | Описание |
| --- | --- | --- |
| `mid` | integer | Идентификатор сообщения (эквивалент `id`). |
| `uid` | integer | Идентификатор пользователя (эквивалент `user_id`). |
| `date` | integer | Время отправки (Unix timestamp). |
| `read_state` | integer | Статус прочтения (`0` или `1`). |
| `out` | integer | Направление сообщения (`0` или `1`). |
| `title` | string | Заголовок диалога. |
| `body` | string | Текст сообщения. |
| `chat_id` | integer | Идентификатор беседы. |
| `attachments` | array | Вложения. |
| `fwd_messages` | array | Пересланные сообщения. |

### Пример объекта (v < 5.0)
```json
{
    "mid": 1050,
    "uid": 1,
    "date": 1696680000,
    "read_state": 1,
    "out": 1,
    "title": "Разработчики OpenVK",
    "body": "Привет всем разработчикам!",
    "chat_id": 1,
    "attachments": []
}
```
