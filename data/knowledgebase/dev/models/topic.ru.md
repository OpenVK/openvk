# Объект Topic

Объект **Topic** описывает тему обсуждения в сообществе ВКонтакте / OpenVK. Структура возвращаемых полей зависит от версии API, переданной в параметре `v`.

---

## Версия API 5.0 и выше (v >= 5.0)

В версиях API 5.0+ используются следующие поля:

| Поле | Тип | Описание |
| --- | --- | --- |
| `id` | integer | Идентификатор темы обсуждения. |
| `title` | string | Заголовок темы. |
| `created` | integer | Время создания темы (Unix timestamp). |
| `created_by` | integer | Идентификатор создателя темы (пользователя или сообщества). |
| `updated` | integer | Время последнего сообщения в теме (Unix timestamp). |
| `updated_by` | integer | Идентификатор автора последнего сообщения. |
| `is_closed` | integer | `1`, если тема закрыта для новых сообщений, иначе `0`. |
| `is_fixed` | integer | `1`, если тема закреплена вверху списка обсуждений, иначе `0`. |
| `comments` | integer | Количество сообщений (комментариев) в теме. |
| `first_comment` | string\|null | *(Опционально)* Текст первого сообщения при запросе с превью. |
| `last_comment` | string\|null | *(Опционально)* Текст последнего сообщения при запросе с превью. |

### Пример объекта (v >= 5.0)
```json
{
    "id": 5,
    "title": "Правила сообщества",
    "created": 1696680000,
    "created_by": 1,
    "updated": 1696683600,
    "updated_by": 1,
    "is_closed": 1,
    "is_fixed": 1,
    "comments": 1
}
```

---

## До версии API 5.0 (v < 5.0)

В версиях API 3.x и 4.x возвращается поле `tid`:

| Поле | Тип | Описание |
| --- | --- | --- |
| `tid` / `id` | integer | Идентификатор темы (эквивалент `id` в API v5.0+). |
| `title` | string | Заголовок темы. |
| `created` | integer | Время создания (Unix timestamp). |
| `created_by` | integer | Идентификатор автора темы. |
| `updated` | integer | Время последнего обновления. |
| `updated_by` | integer | Автор последнего ответа. |
| `is_closed` | integer | Статус закрытости. |
| `is_fixed` | integer | Флаг закрепления. |
| `comments` | integer | Число комментариев. |

### Пример объекта (v < 5.0)
```json
{
    "tid": 5,
    "title": "Правила сообщества",
    "created": 1696680000,
    "created_by": 1,
    "updated": 1696683600,
    "updated_by": 1,
    "is_closed": 1,
    "is_fixed": 1,
    "comments": 1
}
```
