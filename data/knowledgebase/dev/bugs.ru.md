# Баг-трекер и участие в разработке OpenVK

OpenVK — полностью открытый проект с открытым исходным кодом, разрабатываемый сообществом под лицензией **GNU AGPLv3**.

Мы рады любой помощи: сообщениям об ошибках, предложениям по улучшению API и веб-интерфейса, а также Pull Request'ам с исправлениями и новыми возможностями.

---

## Сообщение об ошибке (Bug Report)

Если вы обнаружили ошибку в работе сайта, неточность в ответе API или проблему в документации:

1. **Проверьте существующие Issues:**
   Перейдите в трекер задач на GitHub: [https://github.com/openvk/openvk/issues](https://github.com/openvk/openvk/issues) и убедитесь через поиск, что о проблеме еще не сообщали.

2. **Создайте новое Issue:**
   Нажмите **«New issue»** и подробно заполните шаблон:
   * **Описание проблемы** — кратко и понятно сформулируйте суть ошибки.
   * **Шаги для воспроизведения** — пошаговый сценарий (действия в интерфейсе или отправляемый API-запрос).
   * **Ожидаемое поведение** — как система должна была сработать.
   * **Фактическое поведение** — что произошло на самом деле (с приложением скриншотов или текста ошибки).
   * **Технические детали:**
     - Вызываемый метод API (например, `account.getProfileInfo`) и версия (`v=5.80`).
     - Тело запроса и полученный JSON-ответ.
     - Версия браузера, операционной системы или клиента.
     - Логи сервера из папки `/logs/`, если проблема воспроизводится на вашем инстансе.

## Помощь проекту: исправление ошибок и новые возможности

* **Процесс отправки изменений (Pull Request):**
  1. Сделайте Fork репозитория [openvk/openvk](https://github.com/openvk/openvk).
  2. Создайте ветку для вашего исправления: `git checkout -b fix-account-method`.
  3. Внесите изменения, соблюдая стиль кода проекта (PSR-12 для PHP, чистый ES6/CSS).
  4. Проверьте работоспособность на локальном инстансе.
  5. Отправьте Pull Request в ветку `master` с понятным описанием сделанных изменений.

## Безопасность и уязвимости (Security)

Если вы обнаружили критическую уязвимость безопасности, которая может поставить под угрозу данные пользователей публичных инстансов, пожалуйста, не публикуйте её в открытых Issue.

Сообщите о ней напрямую разработчикам:
* Электронная почта команды безопасности: `contact@openvk.org`
* Личные сообщения [команды OpenVK](https://openvk.org/team)
