# Модели данных

В данном разделе описаны структуры объектов данных, возвращаемые методами OpenVK API.

На эти модели ссылаются ответы различных методов API (например, методы секций `users`, `groups`, `messages`, `wall`, `photos`, `audio`, `video`, `docs` и др.).

### Доступные модели
* **[user](/dev/models/user)** — объект пользователя ВКонтакте / OpenVK.
* **[group](/dev/models/group)** — объект сообщества (группы, публичной страницы или встречи).
* **[chat](/dev/models/chat)** — объект группового чата (до версии API 5.80).
* **[conversation](/dev/models/conversation)** — объект беседы / диалога (начиная с версии API 5.80).
* **[message](/dev/models/message)** — объект личного сообщения или сообщения беседы.
* **[post](/dev/models/post)** — объект записи на стене (поста).
* **[comment](/dev/models/comment)** — объект комментария (к записи, фотографии, видео, заметке).
* **[photo](/dev/models/photo)** — объект фотографии и доступные размеры.
* **[audio](/dev/models/audio)** — объект аудиозаписи.
* **[video](/dev/models/video)** — объект видеозаписи.
* **[doc](/dev/models/doc)** — объект документа / файла.
* **[topic](/dev/models/topic)** — объект темы обсуждения в сообществе.
* **[poll](/dev/models/poll)** — объект опроса (голосования).
* **[note](/dev/models/note)** — объект текстовой заметки.
* **[album](/dev/models/album)** — объект фотоальбома.
* **[playlist](/dev/models/playlist)** — объект музыкального плейлиста.
* **[sticker](/dev/models/sticker)** — объект стикера и набора стикеров.
* **[gift](/dev/models/gift)** — объект отправленного подарка.
