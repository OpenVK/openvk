# Игры и приложения в OpenVK

В данном разделе описан процесс создания, настройки и интеграции встраиваемых приложений (IFrame-приложений, HTML5-игр и мини-приложений), работающих внутри интерфейса социальной сети OpenVK.

---

## 1. Создание приложения

Чтобы создать новое приложение:

1. Перейдите по ссылке [Создать приложение](/editapp?act=create) (или в раздел **Приложения** &rarr; **Управление**).
2. Заполните основные параметры:
   - **Название приложения** — отображается в каталоге и в заголовке окна игры.
   - **Описание** — краткая информация о возможностях приложения.
   - **IFrame URL** — прямой HTTPS-адрес вашего веб-приложения или игры.
   - **Иконка / Аватар** — изображение приложения для каталога.
   - **Заметка с новостями** *(опционально)* — ссылка на заметку с описанием обновлений.
3. После сохранения приложению присваивается уникальный идентификатор `app_id`, и оно становится доступно по адресу `/app{id}`.

## 2. Архитектура интеграции (IFrame и postMessage)

Приложение загружается внутри защищенного контейнера `<iframe>` на странице `/app{id}`.

Взаимодействие между родительской страницей OpenVK и вашим IFrame-приложением происходит через стандартный механизм браузера `window.postMessage`.

### Формат отправки запроса из приложения

Для вызова функций платформы отправьте сообщение родительскому окну:

```javascript
window.parent.postMessage({
    "@type": "VkApiRequest", // Тип запроса
    "transaction": "tx_12345", // Уникальный идентификатор транзакции
    "method": "users.get", // Метод OpenVK API
    "params": {
        "v": "5.80"
    }
}, "*");
```

### Формат получения ответа в приложении

```javascript
window.addEventListener("message", function(event) {
    var data = event.data;
    if (data.transaction === "tx_12345") {
        if (data.ok) {
            console.log("Успешный ответ:", data.response);
        } else {
            console.error("Ошибка:", data.error);
        }
    }
});
```

## 3. Поддерживаемые типы запросов (`@type`)

### `VkApiRequest` — Вызов методов API

Позволяет вызывать методы OpenVK API от имени текущего авторизованного пользователя.

Если метод требует дополнительных прав (`friends`, `wall`, `messages`, `groups`, `likes`), OpenVK автоматически покажет пользователю модальное окно с запросом разрешения.

```javascript
window.parent.postMessage({
    "@type": "VkApiRequest",
    "transaction": "req_users",
    "method": "friends.get",
    "params": {
        "count": 10
    }
}, "*");
```

### `UserInfoRequest` — Получение данных текущего игрока

Возвращает базовую информацию о пользователе, запустившем приложение:

```javascript
window.parent.postMessage({
    "@type": "UserInfoRequest",
    "transaction": "req_user_info"
}, "*");
```

Ответ:
```json
{
    "transaction": "req_user_info",
    "ok": true,
    "user": {
        "id": 1,
        "first_name": "Павел",
        "last_name": "Дуров"
    }
}
```

### `WallPostRequest` — Публикация записи на стену

Запрашивает у пользователя подтверждение на публикацию записи с текстом игры на его стене:

```javascript
window.parent.postMessage({
    "@type": "WallPostRequest",
    "transaction": "req_wall_post",
    "text": "Я набрал 1000 очков в игре OpenVK Runner!"
}, "*");
```

В случае согласия пользователя возвращается объект созданного поста:
```json
{
    "transaction": "req_wall_post",
    "ok": true,
    "post": {
        "id": 42,
        "text": "Я набрал 1000 очков в игре OpenVK Runner!"
    }
}
```

### `PaymentRequest` — Прием платежей (Голоса / Баллы)

Инициирует списание голосов / баллов со счета пользователя за игровую покупку:

```javascript
window.parent.postMessage({
    "@type": "PaymentRequest",
    "transaction": "order_987",
    "outSum": 10,
    "description": "100 золотых монет"
}, "*");
```

После подтверждения пользователем и успешного списания возвращается подпись транзакции:
```json
{
    "transaction": "order_987",
    "ok": true,
    "outSum": 10,
    "description": "100 золотых монет",
    "signature": "sign_hash_hex"
}
```

## 4. Права доступа приложений

| Право | Описание |
| --- | --- |
| `friends` | Доступ к списку друзей пользователя. |
| `wall` | Публикация записей и чтение стены. |
| `messages` | Отправка сообщений от имени пользователя. |
| `groups` | Доступ к сообществам пользователя. |
| `likes` | Управление отметками «Мне нравится». |
