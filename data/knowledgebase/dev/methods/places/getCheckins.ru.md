# places.getCheckins

Возвращает список чекинов по географическим координатам.

> **Примечание (заглушка совместимости):** В текущей версии OpenVK метод является заглушкой для совместимости с мобильными клиентами и возвращает пустой список.

### Авторизация
Метод является публичным и не требует обязательной авторизации.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `latitude` | float | Географическая широта. По умолчанию: `0.0`. |
| `longitude` | float | Географическая долгота. По умолчанию: `0.0`. |
| `offset` | integer | Смещение выборки. По умолчанию: `0`. |
| `count` | integer | Количество возвращаемых отметок. По умолчанию: `20`. |

### Результат

В API версии 5.0 и выше возвращает объект:
* `count` (integer) — количество чекинов (всегда `0`);
* `items` (array) — пустой массив `[]`.

В устаревших версиях API (до версии 5.0) возвращает массив `[0]`.

### Пример запроса
```http
POST /method/places.getCheckins HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

latitude=55.7558&longitude=37.6173&count=10&v=5.138
```

### Пример ответа
```json
{
    "response": {
        "count": 0,
        "items": []
    }
}
```
