# places.getCityById

Возвращает информацию о городах по переданным идентификаторам.

### Авторизация
Метод является публичным и не требует обязательной авторизации.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `cids` | string / integer / array | Идентификаторы городов (число, массив чисел или строка с идентификаторами через запятую). |

### Результат

Возвращает массив объектов городов со следующими полями:
* `id` (integer) — идентификатор города;
* `cid` (integer) — идентификатор города (для совместимости);
* `title` (string) — название города;
* `name` (string) — название города.

### Пример запроса
```http
POST /method/places.getCityById HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

cids=1,2&v=5.138
```

### Пример ответа
```json
{
    "response": [
        {
            "id": 1,
            "cid": 1,
            "title": "Москва",
            "name": "Москва"
        }
    ]
}
```
