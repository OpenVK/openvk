# places.getCountryById

Возвращает информацию о странах по переданным числовым идентификаторам стран.

### Авторизация
Метод является публичным и не требует обязательной авторизации.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `cids` | string / integer / array | Идентификаторы стран (число, массив чисел или строка с идентификаторами через запятую). |

### Результат

Возвращает массив объектов стран со следующими полями:
* `id` (integer) — идентификатор страны;
* `cid` (integer) — идентификатор страны (для совместимости);
* `title` (string) — название страны (например, `"Россия"`, `"Беларусь"`, `"Казахстан"`);
* `name` (string) — название страны.

### Пример запроса
```http
POST /method/places.getCountryById HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

cids=1,3&v=5.138
```

### Пример ответа
```json
{
    "response": [
        {
            "id": 1,
            "cid": 1,
            "title": "Россия",
            "name": "Россия"
        },
        {
            "id": 3,
            "cid": 3,
            "title": "Беларусь",
            "name": "Беларусь"
        }
    ]
}
```
