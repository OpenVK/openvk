# places.checkin

Создает новую гео-отметку (чекин) в указанном месте.

> **Примечание (заглушка совместимости):** В текущей версии OpenVK метод реализован как заглушка для совместимости с мобильными клиентами и возвращает `1`.

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`). Метод выполняет действие записи.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `place_id` | integer | Идентификатор места. По умолчанию: `0`. |
| `text` | string | Текст комментария к гео-отметке. |
| `lat` | float | Географическая широта. По умолчанию: `0.0`. |
| `long` | float | Географическая долгота. По умолчанию: `0.0`. |
| `friends_only` | integer | Флаг видимости только для друзей (`1` — только для друзей, `0` — для всех). По умолчанию: `0`. |
| `services` | string | Список внешних сервисов для экспорта. |

### Результат

Возвращает `1`.

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `5` | `User authorization failed: no access_token passed.` — Пользователь не авторизован. |

### Пример запроса
```http
POST /method/places.checkin HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

place_id=1&text=Я%20здесь&lat=55.7558&long=37.6173&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": 1
}
```
