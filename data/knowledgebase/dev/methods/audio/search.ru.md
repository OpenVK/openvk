# audio.search

Возвращает список аудиозаписей в соответствии с заданным поисковым запросом.

### Авторизация
Для вызова этого метода Ваше приложение должно иметь права с битовой маской `audio`.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `q` | string | Текст поискового запроса. Обязательный параметр. |
| `performer_only` | integer | `1` — поиск только по названию исполнителя. По умолчанию `0`. |
| `lyrics` | integer | `1` — искать только аудиозаписи с текстом. По умолчанию `0`. |
| `sort` | integer | Вид сортировки: `2` — по популярности, `1` — по длительности, `0` — по дате добавления. По умолчанию `2`. |
| `offset` | integer | Смещение относительно начала списка найденных аудиозаписей. По умолчанию `0`. |
| `count` | integer | Количество возвращаемых аудиозаписей. По умолчанию `30`, максимальное значение `300`. |

### Результат
Возвращает объект, содержащий общее количество найденных аудиозаписей в поле `count` и массив объектов аудиозаписей в поле `items`.

### Пример ответа

```json
{
    "response": {
        "count": 1,
        "items": [
            {
                "id": 1,
                "owner_id": 1,
                "artist": "Rick Astley",
                "title": "Never Gonna Give You Up",
                "duration": 213,
                "url": "https://openvk.instance/storage/audio/1_1.mp3"
            }
        ]
    }
}
```
