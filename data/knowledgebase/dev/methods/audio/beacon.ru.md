# audio.beacon

Отправляет сигнал (маяк) о прослушивании аудиозаписи. Метод увеличивает счетчик прослушиваний трека (если с момента предыдущего прослушивания прошло достаточно времени) и обновляет поле последней воспроизводимой композиции у пользователя или сообщества.

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`) с правами доступа `audio`.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `aid` | integer | Глобальный идентификатор аудиозаписи в базе данных (`global_id`). **Обязательный параметр.** |
| `gid` | integer | Идентификатор сообщества, если прослушивание осуществляется от имени сообщества (пользователь должен иметь права администратора). |

### Результат

Возвращает `1`, если прослушивание было успешно зарегистрировано и счетчик увеличен, либо `0`, если трек уже был прослушан недавно.

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `5` | `User authorization failed: no access_token passed.` — Пользователь не авторизован. |
| `201` | `Insufficient permissions to listen this audio` — Доступ к аудиозаписи ограничен. |
| `203` | `Insufficient rights to this group` — Недостаточно прав для работы с сообществом. |
| `404` | `Not Found` — Аудиозапись или сообщество не найдены. |

### Пример запроса
```http
POST /method/audio.beacon HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

aid=105&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": 1
}
```
