# audio.get

Возвращает список аудиозаписей пользователя или сообщества.

### Авторизация
Для вызова этого метода Ваше приложение должно иметь права с битовой маской `audio`.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `owner_id` | integer | Идентификатор владельца аудиозаписей. По умолчанию идентификатор текущего пользователя. |
| `album_id` | integer | Идентификатор альбома (плейлиста). |
| `audio_ids` | string | Идентификаторы аудиозаписей, разделенные запятыми. |
| `need_user` | integer | `1` — возвращать информацию о пользователе, загрузившем аудиозапись. По умолчанию `1`. |
| `offset` | integer | Смещение относительно начала списка. По умолчанию `0`. |
| `count` | integer | Количество аудиозаписей, которое необходимо вернуть. По умолчанию `100`, максимальное значение `100`. |
| `shuffle` | integer | `1` — перемешать аудиозаписи в случайном порядке. По умолчанию `0`. |

### Результат
Возвращает объект, содержащий число результатов в поле `count` и массив объектов аудиозаписей в поле `items`.

Каждый объект аудиозаписи содержит следующие поля:
* `id` — идентификатор аудиозаписи;
* `owner_id` — идентификатор владельца аудиозаписи;
* `artist` — исполнитель;
* `title` — название композиции;
* `duration` — длительность в секундах;
* `url` — прямая ссылка на аудиофайл;
* `lyrics_id` — идентификатор текста песни (если доступен).

### Пример ответа

```json
{
    "response": {
        "count": 2,
        "items": [
            {
                "id": 1,
                "owner_id": 1,
                "artist": "Rick Astley",
                "title": "Never Gonna Give You Up",
                "duration": 213,
                "url": "https://ovk.to/storage/audio/1_1.mp3"
            },
            {
                "id": 2,
                "owner_id": 1,
                "artist": "Darude",
                "title": "Sandstorm",
                "duration": 225,
                "url": "https://ovk.to/storage/audio/1_2.mp3"
            }
        ]
    }
}
```
