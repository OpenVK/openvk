# audio.add

Копирует аудиозапись на страницу пользователя или сообщества.

### Авторизация
Для вызова этого метода Ваше приложение должно иметь права с битовой маской `audio`.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `audio_id` | integer | Идентификатор аудиозаписи. Обязательный параметр. |
| `owner_id` | integer | Идентификатор владельца аудиозаписи. Обязательный параметр. |
| `group_id` | integer | Идентификатор сообщества, в которое необходимо добавить аудиозапись. Если параметр не указан, аудиозапись добавляется текущему пользователю. |

### Результат
Возвращает идентификатор созданной аудиозаписи.

### Пример ответа

```json
{
    "response": 456239020
}
```
