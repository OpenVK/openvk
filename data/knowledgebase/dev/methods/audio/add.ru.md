# audio.add

Копирует аудиозапись в коллекцию текущего пользователя или сообщества.

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`) с правами доступа `audio`.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `audio_id` | integer | Виртуальный идентификатор аудиозаписи на странице владельца. **Обязательный параметр.** |
| `owner_id` | integer | Идентификатор владельца аудиозаписи. **Обязательный параметр.** |
| `group_id` | integer | Идентификатор сообщества, в коллекцию которого необходимо добавить аудиозапись (текущий пользователь должен иметь права администратора сообщества). Если не указан, аудиозапись добавляется текущему пользователю. |
| `album_id` | integer | *(Не поддерживается)* При передаче возвращает ошибку 10. |

### Результат

Возвращает строковый идентификатор добавленной аудиозаписи в формате `owner_id_virtual_id` (например, `"1_45"`).

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `5` | `User authorization failed: no access_token passed.` — Пользователь не авторизован. |
| `10` | `album_id not implemented` — Параметр `album_id` не поддерживается. |
| `201` | `Access denied to audio(owner={owner_id}, vid={audio_id})` — Доступ к аудиозаписи ограничен. |
| `203` | `Insufficient rights to this group` — Недостаточно прав для управления аудиозаписями сообщества. |
| `300` | `Album is full` — Достигнут лимит на количество аудиозаписей. |
| `404` | `Not found` / `Invalid group_id` — Аудиозапись или сообщество не найдены. |

### Пример запроса
```http
POST /method/audio.add HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

audio_id=1&owner_id=2&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": "1_45"
}
```
