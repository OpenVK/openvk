# audio.addAlbum

Создает новый плейлист (альбом) для пользователя или сообщества.

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`) с правами доступа `audio`.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `title` | string | Название плейлиста. **Обязательный параметр.** |
| `description` | string | Описание плейлиста. |
| `group_id` | integer | Идентификатор сообщества (если плейлист создается для сообщества; требуются права администратора). По умолчанию: `0` (создается для текущего пользователя). |

### Результат

Возвращает целочисленный идентификатор созданного плейлиста (`album_id`).

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `5` | `User authorization failed: no access_token passed.` — Пользователь не авторизован. |
| `404` | `Invalid group_id` — Указанное сообщество не найдено. |
| `600` | `Insufficient rights to this group` — Недостаточно прав для создания плейлиста в сообществе. |

### Пример запроса
```http
POST /method/audio.addAlbum HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

title=Новый+плейлист&description=Описание+плейлиста&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": 42
}
```
