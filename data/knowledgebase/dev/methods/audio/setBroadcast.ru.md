# audio.setBroadcast

Транслирует воспроизводимую аудиозапись в статус текущего пользователя или управляемого сообщества.

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`) с правами доступа `audio` и `status`.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `audio` | string | Идентификатор аудиозаписи в формате `owner_id_audio_id` (например, `1_45`). Если необходимо отключить трансляцию, можно передать `0_0`. **Обязательный параметр.** |
| `target_ids` | string | Идентификаторы целевых объектов через запятую (ID текущего пользователя или отрицательные ID сообществ `-gid`). **Обязательный параметр.** |

### Результат

Возвращает массив числовых идентификаторов объектов, для которых успешно включена трансляция (например, `[1, -5]`).

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `5` | `User authorization failed: no access_token passed.` — Пользователь не авторизован. |
| `203` | `Insufficient rights to this group` — Недостаточно прав для управления трансляцией в сообществе. |
| `404` | `Not Found` — Сообщество не найдено. |
| `600` | `Can't listen on behalf of {id}` — Нельзя транслировать музыку от имени другого пользователя. |

### Пример запроса
```http
POST /method/audio.setBroadcast HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

audio=1_45&target_ids=1,-12&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": [
        1,
        -12
    ]
}
```
