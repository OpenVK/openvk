# audio.getPlaylistById

Возвращает базовую информацию о плейлисте (альбоме) по его виртуальному идентификатору и идентификатору владельца.

### Авторизация
Для вызова этого метода не требуется обязательная авторизация пользователя.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `owner_id` | integer | Идентификатор владельца плейлиста (пользователя или сообщества). По умолчанию: `0`. |
| `playlist_id` | integer | Виртуальный идентификатор плейлиста. По умолчанию: `0`. |

### Результат

Возвращает объект плейлиста со следующими полями:
* `id` (integer) — глобальный идентификатор плейлиста;
* `owner_id` (integer) — идентификатор владельца;
* `title` (string) — название плейлиста;
* `cover_url` (string) — ссылка на изображение обложки.

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `15` | `Access error` — Плейлист не найден, удален или доступ к нему ограничен. |

### Пример запроса
```http
POST /method/audio.getPlaylistById HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

owner_id=1&playlist_id=1&v=5.138
```

### Пример ответа
```json
{
    "response": {
        "id": 1,
        "owner_id": 1,
        "title": "Любимая музыка",
        "cover_url": "/storage/covers/playlist_1.jpg"
    }
}
```
