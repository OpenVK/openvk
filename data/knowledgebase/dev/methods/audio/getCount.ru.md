# audio.getCount

Возвращает общее количество аудиозаписей на странице пользователя или сообщества.

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`) с правами доступа `audio`.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `owner_id` | integer | Идентификатор владельца аудиозаписей (положительное число — ID пользователя, отрицательное — ID сообщества). **Обязательный параметр.** |
| `uploaded_only` | integer | `1` — подсчитывать только аудиозаписи, непосредственно загруженные текущим пользователем (работает только для `owner_id` текущего пользователя), `0` — вся коллекция. По умолчанию: `0`. |

### Результат

Возвращает целочисленное значение (integer) — общее число аудиозаписей.

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `5` | `User authorization failed: no access_token passed.` — Пользователь не авторизован. |
| `15` | `Access denied` — Доступ к аудиозаписям ограничен настройками приватности пользователя. |
| `404` | `User not found` / `Group not found` — Пользователь или сообщество не найдены. |

### Пример запроса
```http
POST /method/audio.getCount HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

owner_id=1&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": 42
}
```
