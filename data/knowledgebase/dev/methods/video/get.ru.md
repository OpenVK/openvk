# video.get

Возвращает список видеозаписей пользователя или сообщества в соответствии с заданными критериями, либо подробную информацию о конкретных видеозаписях по их идентификаторам.

### Авторизация
Этот метод не требует обязательной авторизации при просмотре открытых видеозаписей. Если `owner_id` не указан, используется ID текущего авторизованного пользователя.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `owner_id` | integer | Идентификатор владельца видеозаписей (положительное число — пользователь, отрицательное — сообщество). По умолчанию: ID текущего пользователя. |
| `videos` | string | Идентификаторы видеозаписей через запятую в формате `<owner_id>_<video_id>` (до 100 штук), например `1_45,-10_20`. |
| `video_id` | integer | Идентификатор конкретного видео (используется при пустом `videos`). |
| `gid` | integer | Идентификатор сообщества (альтернатива отрицательному `owner_id`). |
| `offset` | integer | Смещение относительно начала списка для выборки. По умолчанию: `0`. |
| `count` | integer | Количество возвращаемых видеозаписей (максимум `100`). По умолчанию: `30`. |
| `extended` | integer | `1` — возвращать дополнительные массивы `profiles` и `groups`, `0` — только список видеозаписей. По умолчанию: `0`. |
| `fields` | string | Список дополнительных полей профилей и групп, разделенных запятыми (при `extended=1`). |

### Результат

Возвращает объект со следующими полями:

| Поле | Тип | Описание |
| --- | --- | --- |
| `count` | integer | Общее количество видеозаписей. |
| `items` | array | Массив объектов видеозаписей. |
| `profiles` | array | Профили авторов видео (при `extended=1`). |
| `groups` | array | Сообщества авторов видео (при `extended=1`). |

Каждый объект видеозаписи в `items` содержит:
* `id` (integer) — идентификатор видеозаписи.
* `owner_id` (integer) — идентификатор владельца видеозаписи.
* `title` (string) — название видео.
* `description` (string) — описание видео.
* `duration` (integer) — длительность в секундах.
* `photo_320` (string) — URL обложки видеозаписи.
* `date` (integer) — дата загрузки в формате unixtime.
* `views` (integer) — количество просмотров.
* `comments` (integer) — количество комментариев.
* `player` (string) — URL встроенного плеера.

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `14` | `Invalid user` — пользователь или сообщество не найдено либо удалено. |
| `15` | `Too many ids given` — передано более 100 идентификаторов в параметре `videos`. |
| `21` | `This user chose to hide his videos.` — доступ к видеозаписям ограничен настройками приватности. |

### Пример запроса
```http
POST /method/video.get HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

owner_id=1&count=2&v=5.138
```
