# video.getComments

Возвращает список комментариев к видеозаписи.

### Авторизация
Для вызова этого метода необходим токен пользователя.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `video_id` | integer | **Обязательный параметр.** Идентификатор видеозаписи. |
| `owner_id` | integer | Идентификатор владельца видеозаписи (положительное число — пользователь, отрицательное — сообщество). По умолчанию: ID текущего пользователя. |
| `need_likes` | integer | Возвращать ли информацию об отметках «Мне нравится» (по умолчанию: `0`). |
| `offset` | integer | Смещение для выборки комментариев. По умолчанию: `0`. |
| `count` | integer | Количество возвращаемых комментариев. По умолчанию: `20`. |
| `sort` | string | Порядок сортировки комментариев: `"asc"` — в хронологическом порядке (от старых к новым), `"desc"` — в обратном порядке (от новых к старым). По умолчанию: `"asc"`. |

### Результат

Возвращает объект со следующими полями:

| Поле | Тип | Описание |
| --- | --- | --- |
| `count` | integer | Общее количество комментариев к видеозаписи. |
| `items` | array | Массив объектов комментариев. |

Каждый объект комментария в `items` содержит:
* `id` (integer) — идентификатор комментария.
* `from_id` (integer) — автор комментария (ID пользователя или отрицательный ID сообщества).
* `date` (integer) — дата публикации комментария в формате unixtime.
* `text` (string) — текст комментария.
* `reply_to_cid` (integer) — идентификатор комментария, ответом на который является данный комментарий (если есть).
* `reply_to_uid` (integer) — идентификатор автора комментария, на который оставлен ответ.
* `likes` (object) — информация об отметках «Мне нравится»: `count` (число лайков), `user_likes` (поставил ли лайк текущий пользователь: `1` или `0`), `can_like` (`1`).

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `100` | `One of the parameters specified was missing or invalid: video not found` — видеозапись не найдена или удалена. |

### Пример запроса
```http
POST /method/video.getComments HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

owner_id=1&video_id=1&count=2&access_token=YOUR_ACCESS_TOKEN&v=5.138
```
