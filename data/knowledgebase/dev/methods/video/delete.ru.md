# video.delete

Удаляет видеозапись со страницы пользователя или сообщества.

### Авторизация
Для вызова этого метода необходим токен пользователя с правами доступа к видеозаписям (`video`).

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `owner_id` | integer | **Обязательный параметр.** Идентификатор владельца видеозаписи (положительное число — пользователь, отрицательное — сообщество). |
| `video_id` | integer | **Обязательный параметр.** Идентификатор видеозаписи. |
| `target_id` | integer | Идентификатор владельца при удалении из добавленных видео (зарезервировано). |

### Результат

Возвращает `1` при успешном удалении.

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `14` | `Access denied` — видеозапись не найдена, уже удалена или у текущего пользователя нет прав на ее удаление. |
| `-40` | `Videos cannot be collected at this moment.` — удаление добавленных видеозаписей временно не поддерживается. |

### Пример запроса
```http
POST /method/video.delete HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

owner_id=1&video_id=1&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": 1
}
```
