# video.search

Возвращает список видеозаписей в соответствии с заданным поисковым запросом.

### Авторизация
Для вызова этого метода необходим токен пользователя.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `q` | string | Поисковая строка для поиска по названию и описанию видео. |
| `sort` | integer | Порядок сортировки: `0` — по дате добавления, `1` — по длительности, `2` — по релевантности. По умолчанию: `0`. |
| `offset` | integer | Смещение относительно начала списка для выборки. По умолчанию: `0`. |
| `count` | integer | Количество возвращаемых видеозаписей. По умолчанию: `10`. |
| `extended` | boolean / integer | `1` — возвращать информацию о пользователях и сообществах (`profiles`, `groups`), `0` — только видеозаписи. По умолчанию: `0`. |
| `fields` | string | Список дополнительных полей профилей и групп через запятую (при `extended=1`). |

### Результат

Возвращает объект со следующими полями:

| Поле | Тип | Описание |
| --- | --- | --- |
| `count` | integer | Общее количество найденных видеозаписей. |
| `items` | array | Массив объектов видеозаписей. |
| `profiles` | array | Профили авторов найденных видео (при `extended=1`). |
| `groups` | array | Сообщества авторов найденных видео (при `extended=1`). |

### Пример запроса
```http
POST /method/video.search HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

q=конференция&count=5&access_token=YOUR_ACCESS_TOKEN&v=5.138
```
