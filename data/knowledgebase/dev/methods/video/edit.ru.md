# video.edit

Редактирует информацию о видеозаписи (название и описание) на странице пользователя или сообщества.

### Авторизация
Для вызова этого метода необходим токен пользователя с правами на управление видеозаписями (`video`).

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `owner_id` | integer | **Обязательный параметр.** Идентификатор владельца видеозаписи (положительное число — пользователь, отрицательное — сообщество). |
| `video_id` | integer | **Обязательный параметр.** Идентификатор видеозаписи. |
| `name` | string | Новое название видеозаписи. |
| `desc` | string | Новое описание видеозаписи. |
| `no_comments` | integer | Отключение возможности комментирования (зарезервировано). |
| `repeat` | integer | Зацикливание воспроизведения (зарезервировано). |

### Результат

Возвращает объект с подтверждением успешного обновления:

| Поле | Тип | Описание |
| --- | --- | --- |
| `success` | integer | Всегда `1` при успешном редактировании. |

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `14` | `Access denied` — видеозапись не найдена, удалена или у текущего пользователя недостаточно прав для её редактирования. |

### Пример запроса
```http
POST /method/video.edit HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

owner_id=1&video_id=1&name=Обновленное+название&desc=Новое+описание&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": {
        "success": 1
    }
}
```
