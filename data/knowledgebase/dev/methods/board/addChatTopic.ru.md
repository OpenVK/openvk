# board.addChatTopic

Создает в обсуждениях сообщества тему особого типа (`type = "chat"`), привязанную к групповой беседе (чату). Если параметр `chat_id` не передан, создается новая беседа с названием `title`. Если передан существующий `chat_id`, тема связывается с уже созданным чатом.

> **Примечание:** Метод доступен только администраторам сообщества. Для привязки существующего чата пользователь также должен быть администратором этого чата, и чат не должен быть привязан к другой теме.

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`).

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `group_id` | integer | Идентификатор сообщества. **Обязательный параметр.** |
| `title` | string | Название беседы (используется при создании нового чата). **Обязательный параметр.** |
| `chat_id` | string | Идентификатор существующего чата (например, `12` или peer ID `2000000012`), который необходимо привязать к теме. Если не указан, создается новый чат. |

### Результат

Возвращает числовой идентификатор созданной темы в сообществе (`topic_id`).

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `-5` | `Invalid chat` — Не удалось создать или привязать чат. |
| `5` | `User authorization failed: no access_token passed.` — Пользователь не авторизован. |
| `14` | `Chat already linked to some topic` — Чат уже привязан к другому обсуждению. |
| `15` | `Access denied` — Нет прав администратора сообщества или чата. |

### Пример запроса
```http
POST /method/board.addChatTopic HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

group_id=1&title=Официальная+беседа&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": 7
}
```
