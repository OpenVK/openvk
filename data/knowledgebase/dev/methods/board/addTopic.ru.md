# board.addTopic

Создает новую тему в обсуждениях сообщества.

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`).

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `group_id` | integer | Идентификатор сообщества. **Обязательный параметр.** |
| `title` | string | Название темы (до 127 символов). **Обязательный параметр.** |
| `text` | string | Текст первого комментария в теме. |
| `from_group` | boolean | `true` — опубликовать тему от имени сообщества (доступно администраторам сообщества), `false` — от имени текущего пользователя. По умолчанию: `true`. |

### Результат

Возвращает числовой идентификатор созданной темы внутри сообщества (`topic_id`).

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `5` | `User authorization failed: no access_token passed.` — Пользователь не авторизован. |
| `15` | `Access denied` — Сообщество не найдено либо у пользователя нет прав на создание тем в данном сообществе. |

### Пример запроса
```http
POST /method/board.addTopic HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

group_id=1&title=Обсуждение+нового+релиза&text=Делитесь+своими+впечатлениями!&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": 6
}
```
