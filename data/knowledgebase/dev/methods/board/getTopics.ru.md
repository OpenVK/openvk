# board.getTopics

Возвращает список обсуждений (тем) в сообществе. Поддерживает выборку по списку идентификаторов, предпросмотр первого и последнего комментария, а также определение прав на создание тем.

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`).

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `group_id` | integer | Идентификатор сообщества (положительное число). **Обязательный параметр.** |
| `topic_ids` | string | Список идентификаторов тем через запятую (например, `1,2,5`). Если передан, возвращаются только указанные темы. |
| `offset` | integer | Смещение относительно начала списка тем. По умолчанию: `0`. |
| `count` | integer | Количество возвращаемых тем (от `1` до `100`). По умолчанию: `10`. |
| `extended` | boolean | `true` — возвращать информацию о пользователях и сообществах. По умолчанию: `false`. |
| `preview` | integer | `1` — включать в ответ текст первого (`first_comment`) и последнего (`last_comment`) сообщений темы, `0` — не включать. По умолчанию: `0`. |
| `preview_length` | integer | Максимальная длина текста первого и последнего сообщений (в символах). По умолчанию: `90`. |

### Результат

В API версии 5.0 и выше возвращает объект со следующими полями:
* `count` (integer) — общее количество тем в сообществе;
* `items` (array) — массив объектов тем обсуждений;
* `can_add_topics` (integer) — `1`, если текущий пользователь может создавать темы в данном сообществе, `0` — если нет;
* `default_order` (integer) — порядок сортировки по умолчанию (`1` — по дате последнего обновления);
* `topics` (array) — массив объектов тем (для обратной совместимости).

Каждый объект темы содержит:

| Поле | Тип | Описание |
| --- | --- | --- |
| `id` | integer | Идентификатор темы внутри сообщества (виртуальный ID). |
| `tid` | integer | Синоним `id`. |
| `title` | string | Заголовок обсуждения (или название привязанного чата). |
| `created` | integer | Время создания темы (Unix timestamp). |
| `created_by` | integer | Идентификатор автора темы (положительный — пользователь, отрицательный — сообщество). |
| `updated` | integer | Время последнего сообщения/обновления темы (Unix timestamp). |
| `updated_by` | integer | Идентификатор автора последнего сообщения. |
| `is_closed` | integer | `1` — тема закрыта, `0` — открыта для новых комментариев. |
| `is_fixed` | integer | `1` — тема закреплена вверху списка, `0` — обычная. |
| `comments` | integer | Количество комментариев в теме. |
| `type` | string | Тип темы: `"topic"` (стандартное обсуждение) или `"chat"` (привязанная беседа). |
| `first_comment` | string | Текст первого сообщения (если передан `preview=1`). |
| `last_comment` | string | Текст последнего сообщения (если передан `preview=1`). |

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `4` | `Invalid count` — Параметр `count` меньше 1 или больше 100. |
| `5` | `User authorization failed: no access_token passed.` — Пользователь не авторизован. |
| `15` | `Access denied` — Сообщество не найдено либо доступ к нему ограничен. |

### Пример запроса
```http
POST /method/board.getTopics HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

group_id=1&preview=1&count=2&access_token=YOUR_ACCESS_TOKEN&v=5.138
```
