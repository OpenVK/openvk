# board.getComments

Возвращает список комментариев (сообщений) в теме обсуждения.

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`).

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `group_id` | integer | Идентификатор сообщества. **Обязательный параметр.** |
| `topic_id` | integer | Идентификатор темы обсуждения. **Обязательный параметр.** |
| `need_likes` | boolean | `true` — возвращать информацию об отметках «Мне нравится» к комментариям. По умолчанию: `false`. |
| `offset` | integer | Смещение относительно начала списка комментариев. По умолчанию: `0`. |
| `count` | integer | Количество комментариев, которое необходимо вернуть (от `1` до `100`). По умолчанию: `10`. |
| `extended` | boolean | `true` — возвращать дополнительные массивы `profiles` и `groups` с информацией об авторах комментариев. По умолчанию: `false`. |

### Результат

В API версии 5.0 и выше возвращает объект с полями:
* `count` (integer) — общее количество комментариев в теме;
* `items` (array) — массив объектов комментариев;
* `profiles` (array, опционально) — массив профилей авторов комментариев (если `extended = true`);
* `groups` (array, опционально) — массив сообществ (если комментарии оставлялись от имени сообществ и `extended = true`).

В API версии ниже 5.0 возвращается объект со структурой `{"comments": [count, comment1, ...], "profiles": [...], "groups": [...]}`.

Каждый объект комментария содержит:
* `id` (integer) — идентификатор комментария;
* `from_id` (integer) — идентификатор автора комментария;
* `date` (integer) — дата публикации (Unix timestamp);
* `text` (string) — текст комментария;
* `attachments` (array, опционально) — массив прикреплений (фотографии, видео, аудио, стикеры);
* `likes` (object, опционально) — объект счетчика лайков (`count`, `user_likes`, `can_like`).

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `4` | `Invalid count` — Параметр `count` вне диапазона 1..100. |
| `5` | `Not found` — Тема обсуждения не найдена или удалена. |

### Пример запроса
```http
POST /method/board.getComments HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

group_id=1&topic_id=1&need_likes=1&extended=1&access_token=YOUR_ACCESS_TOKEN&v=5.138
```
