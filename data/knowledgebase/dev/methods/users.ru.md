# Методы секции users

Секция **users** содержит методы для получения подробной информации о пользователях и поиска пользователей по параметрам.

### Список методов
* **[users.get](/dev/methods/users/get)** — возвращает расширенную информацию о пользователях.
* **[users.search](/dev/methods/users/search)** — возвращает список пользователей в соответствии с критериями поиска.
