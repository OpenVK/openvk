# Методы users

Секция **users** содержит методы для получения подробной информации о профилях пользователей, списка подписчиков, поиска по базе пользователей и отправки жалоб.

## Список методов

* **[users.get](/dev/methods/users/get)** — возвращает расширенную информацию о пользователях.
* **[users.getFollowers](/dev/methods/users/getFollowers)** — возвращает список подписчиков пользователя.
* **[users.search](/dev/methods/users/search)** — возвращает список пользователей в соответствии с критериями поиска.
* **[users.report](/dev/methods/users/report)** — отправляет жалобу на профиль пользователя.
