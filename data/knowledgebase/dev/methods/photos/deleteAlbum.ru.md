# photos.deleteAlbum

Удаляет фотоальбом пользователя или сообщества вместе со всеми содержащимися в нем фотографиями.

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`) с правами доступа `photos`.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `album_id` | integer | **Обязательный параметр.** Идентификатор удаляемого альбома. |
| `group_id` | integer | Идентификатор сообщества (необязательно, если альбом принадлежит сообществу). |

> **Примечание:** Системные альбомы (аватары, фотографии со стены) удалить нельзя.

### Результат

Возвращает `1` в случае успешного удаления альбома.

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `5` | `User authorization failed: no access_token passed.` — Пользователь не авторизован. |
| `15` | `Access denied` — Альбом не найден, уже удален, является системным или у пользователя нет прав на его удаление. |

### Пример запроса
```http
POST /method/photos.deleteAlbum HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

album_id=1&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": 1
}
```
