# photos.editAlbum

Редактирует название и описание существующего фотоальбома.

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`) с правами доступа `photos`.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `album_id` | integer | **Обязательный параметр.** Идентификатор редактируемого фотоальбома. |
| `owner_id` | integer | **Обязательный параметр.** Идентификатор владельца альбома (положительное число — пользователь, отрицательное — сообщество). |
| `title` | string | Новое название фотоальбома. |
| `description` | string | Новое описание фотоальбома. |
| `privacy` | integer | Уровень приватности. По умолчанию: `0`. |

> **Примечание:** Системные альбомы (аватары, фотографии со стены, сохраненные фотографии) редактировать через данный метод запрещено.

### Результат

Возвращает `1` в случае успешного обновления альбома.

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `5` | `User authorization failed: no access_token passed.` — Пользователь не авторизован. |
| `15` | `Access denied` — Нет прав на редактирование альбома. |
| `114` | `Invalid album id` — Указанный альбом не найден, удален или является системным. |

### Пример запроса
```http
POST /method/photos.editAlbum HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

album_id=1&owner_id=1&title=Обновленный%20альбом&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": 1
}
```
