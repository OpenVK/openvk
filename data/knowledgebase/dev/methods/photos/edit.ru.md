# photos.edit

Изменяет описание (текстовую подпись) к фотографии.

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`) с правами доступа `photos`.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `owner_id` | integer | **Обязательный параметр.** Идентификатор владельца фотографии (положительное число — ID пользователя, отрицательное — ID сообщества). |
| `photo_id` | integer | **Обязательный параметр.** Идентификатор фотографии. |
| `caption` | string | Новый текст описания (подписи) к фотографии. |

### Результат

Возвращает `1` в случае успешного сохранения изменений.

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `5` | `User authorization failed: no access_token passed.` — Пользователь не авторизован. |
| `21` | `Access denied` — Фотография не найдена, удалена или у пользователя нет прав на ее редактирование. |

### Пример запроса
```http
POST /method/photos.edit HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

owner_id=1&photo_id=1&caption=Новое%20описание%20фото&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": 1
}
```
