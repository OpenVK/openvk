# photos.getAlbums

Возвращает список фотоальбомов пользователя или сообщества.

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`) с правами доступа `photos`.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `owner_id` | integer | Идентификатор владельца альбомов (положительное число — ID пользователя, отрицательное — ID сообщества). По умолчанию: ID текущего пользователя. |
| `album_ids` | string | Список идентификаторов альбомов через запятую. Если указан, возвращаются только указанные альбомы. |
| `offset` | integer | Смещение относительно начала списка альбомов. По умолчанию: `0`. |
| `count` | integer | Количество альбомов, которое необходимо вернуть. По умолчанию: `100`. |
| `need_system` | boolean | `1` — возвращать системные альбомы (аватары, фото на стене), `0` — скрывать системные альбомы. По умолчанию: `1`. |
| `need_covers` | boolean | `1` — возвращать поле `thumb_src` и размеры обложки альбома, `0` — нет. По умолчанию: `1`. |
| `photo_sizes` | boolean | `1` — возвращать массив размеров `sizes` для обложки альбома, `0` — нет. По умолчанию: `0`. |

### Результат

В API версии 5.0 и выше возвращает объект с полями:
* `count` (integer) — общее количество альбомов;
* `items` (array) — массив объектов фотоальбомов.

В API версии ниже 5.0 возвращается массив объектов фотоальбомов напрямую (`[album1, album2, ...]`).

Каждый объект альбома содержит:
| Поле | Тип | Описание |
| --- | --- | --- |
| `id` | integer | Идентификатор фотоальбома. |
| `aid` | integer | Идентификатор фотоальбома (для совместимости). |
| `thumb_id` | integer | Идентификатор фотографии-обложки альбома (`0`, если обложка не задана). |
| `owner_id` | integer | Идентификатор владельца альбома. |
| `title` | string | Название альбома. |
| `description` | string | Описание альбома. |
| `created` | integer | Дата создания альбома (Unix timestamp). |
| `updated` | integer | Дата последнего обновления альбома (Unix timestamp). |
| `size` | integer | Количество фотографий в альбоме. |
| `privacy` | integer | Уровень приватности. |
| `privacy_comment` | integer | Уровень приватности комментариев. |
| `upload_by_admins_only` | integer | `1` — загрузка доступна только администраторам. |
| `comments_disabled` | integer | `0` — комментарии включены, `1` — отключены. |
| `can_upload` | integer | `1`, если текущий пользователь может загружать фото в альбом. |
| `thumb_src` | string | URL изображения обложки альбома. |
| `sizes` | array | Массив объектов с различными размерами обложки (если передан `photo_sizes=1` и `need_covers=1`). |

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `5` | `User authorization failed: no access_token passed.` — Пользователь не авторизован. |
| `15` | `Access denied` — Доступ к альбомам пользователя или сообщества ограничен настройками приватности. |

### Пример запроса
```http
POST /method/photos.getAlbums HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

owner_id=1&need_covers=1&photo_sizes=1&access_token=YOUR_ACCESS_TOKEN&v=5.138
```
