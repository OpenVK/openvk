# photos.getComments

Возвращает список комментариев к фотографии.

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`) с правами доступа `photos`.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `owner_id` | integer | **Обязательный параметр.** Идентификатор владельца фотографии (положительное число — ID пользователя, отрицательное — ID сообщества). |
| `photo_id` | integer | Идентификатор фотографии. |
| `pid` | integer | Альтернативный идентификатор фотографии (для совместимости). |
| `need_likes` | boolean | `1` — возвращать информацию о лайках к комментариям, `0` — нет. По умолчанию: `0`. |
| `offset` | integer | Смещение относительно начала списка комментариев. По умолчанию: `0`. |
| `count` | integer | Количество комментариев, которое необходимо вернуть. По умолчанию: `100`. |
| `sort` | string | Порядок сортировки: `asc` — в хронологическом порядке, `desc` — в обратном порядке (сначала новые). По умолчанию: `asc`. |
| `extended` | boolean | `1` — возвращать информацию о пользователях в массиве `profiles`, `0` — нет. По умолчанию: `0`. |
| `fields` | string | Список дополнительных полей профилей пользователей через запятую (при `extended=1`). |

### Результат

В API версии 5.0 и выше возвращает объект с полями:
* `count` (integer) — общее количество комментариев к фото;
* `items` (array) — массив объектов комментариев;
* `profiles` (array, опционально) — массив объектов авторов комментариев (если передан `extended=1`).

В API версии ниже 5.0 возвращается массив, где первый элемент — общее количество комментариев, далее следуют объекты комментариев (`[count, comment1, comment2, ...]`).

Каждый объект комментария содержит:
| Поле | Тип | Описание |
| --- | --- | --- |
| `id` | integer | Идентификатор комментария. |
| `from_id` | integer | Идентификатор автора комментария. |
| `date` | integer | Дата добавления комментария (Unix timestamp). |
| `text` | string | Текст комментария. |
| `reply_to_comment` | integer | Идентификатор родительского комментария (если ответ). |
| `attachments` | array | Массив вложений к комментарию (стикеры и медиафайлы). |
| `likes` | object | Информация о лайках к комментарию (если `need_likes=1`). |

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `5` | `User authorization failed: no access_token passed.` — Пользователь не авторизован. |
| `15` | `Access denied` — Фотография не найдена, удалена или доступ закрыт настройками приватности. |

### Пример запроса
```http
POST /method/photos.getComments HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

owner_id=1&photo_id=1&need_likes=1&extended=1&access_token=YOUR_ACCESS_TOKEN&v=5.138
```
