# photos.putTag

Добавляет отметку пользователя на фотографии.

> **Примечание:** В OpenVK метод является заглушкой для совместимости с клиентами и всегда возвращает `1`.

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`) с правами доступа `photos`.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `owner_id` | integer | **Обязательный параметр.** Идентификатор владельца фотографии. |
| `photo_id` | integer | Идентификатор фотографии. |
| `pid` | integer | Альтернативный идентификатор фотографии. |
| `uid` | integer | Идентификатор отмечаемого пользователя. |
| `x` | float | Координата левого верхнего угла отметки по горизонтали в процентах (0.0 — 100.0). |
| `y` | float | Координата левого верхнего угла отметки по вертикали в процентах (0.0 — 100.0). |
| `x2` | float | Координата правого нижнего угла отметки по горизонтали в процентах. По умолчанию: `100.0`. |
| `y2` | float | Координата правого нижнего угла отметки по вертикали в процентах. По умолчанию: `100.0`. |

### Результат

Возвращает `1`.

### Пример запроса
```http
POST /method/photos.putTag HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

owner_id=1&photo_id=1&uid=2&x=10.5&y=20.0&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": 1
}
```
