# photos.getAlbumsCount

Возвращает количество фотоальбомов пользователя или сообщества.

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`) с правами доступа `photos`.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `user_id` | integer | Идентификатор пользователя, количество альбомов которого нужно получить. |
| `group_id` | integer | Идентификатор сообщества, количество альбомов которого нужно получить. |

> **Примечание:** Если ни один параметр не указан, возвращается количество альбомов текущего пользователя.

### Результат

Возвращает число (integer) — количество доступных фотоальбомов.

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `5` | `User authorization failed: no access_token passed.` — Пользователь не авторизован. |
| `15` | `Access denied` — Доступ к альбомам пользователя или сообщества ограничен приватностью. |

### Пример запроса
```http
POST /method/photos.getAlbumsCount HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

user_id=1&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": 4
}
```
