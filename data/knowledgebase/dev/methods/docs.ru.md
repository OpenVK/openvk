# Методы секции docs

Секция **docs** содержит методы для работы с документами пользователя или сообщества: получение списка файлов, поиск, редактирование метаданных, удаление, добавление в коллекцию, а также группировка по типам и тегам.

### Работа с документами
* **[docs.get](/dev/methods/docs/get)** — возвращает список документов текущего пользователя или сообщества с поддержкой фильтрации по типам и тегам.
* **[docs.getById](/dev/methods/docs/getById)** — возвращает информацию о документах по их идентификаторам (с ключами доступа).
* **[docs.getTypes](/dev/methods/docs/getTypes)** — возвращает категории типов документов и счетчики файлов в каждой категории.
* **[docs.getTags](/dev/methods/docs/getTags)** — возвращает список тегов, используемых в документах пользователя.
* **[docs.search](/dev/methods/docs/search)** — осуществляет поиск по общедоступным документам платформы по названию или тегам.
* **[docs.add](/dev/methods/docs/add)** — копирует документ в коллекцию текущего пользователя.
* **[docs.edit](/dev/methods/docs/edit)** — редактирует название, теги, видимость и папку документа.
* **[docs.delete](/dev/methods/docs/delete)** — удаляет документ из коллекции.
* **[docs.restore](/dev/methods/docs/restore)** — восстанавливает ранее удаленный документ.

### Загрузка документов
* **[docs.getUploadServer](/dev/methods/docs/getUploadServer)** — возвращает адрес сервера для загрузки документов (заглушка).
* **[docs.getWallUploadServer](/dev/methods/docs/getWallUploadServer)** — возвращает адрес сервера для загрузки документов на стену (заглушка).
* **[docs.save](/dev/methods/docs/save)** — сохраняет загруженный документ после передачи файла на сервер (заглушка).
