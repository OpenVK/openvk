# internal.getNotifications

Возвращает список служебных оповещений и сообщений дня (MOTD), запрашиваемых старыми версиями официального клиента ВКонтакте (версий 2.x) при запуске. В OpenVK метод является совместимой заглушкой и возвращает пустой массив.

### Авторизация
Для вызова этого метода авторизация не требуется.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `device` | string | Модель или идентификатор устройства клиента. По умолчанию: `null`. |
| `os` | string | Название и версия операционной системы. По умолчанию: `null`. |
| `app_version` | string / integer | Версия клиентского приложения. По умолчанию: `null`. |
| `locale` | string | Языковой код локали приложения (например, `ru`, `en`). По умолчанию: `null`. |

### Результат

Возвращает массив объектов служебных уведомлений (в текущей реализации OpenVK всегда возвращает пустой массив `[]`).

### Пример запроса
```http
POST /method/internal.getNotifications HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

device=iphone&os=ios+4.3&app_version=2.0&locale=ru&v=5.138
```

### Пример ответа
```json
{
    "response": []
}
```
