# status.set

Устанавливает новый текстовый статус текущего пользователя или описание управляемого сообщества.

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`) с правами доступа `status`.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `text` | string | **Обязательный параметр.** Новый текст статуса или описания сообщества. |
| `group_id` | integer | Идентификатор сообщества, если обновляется описание группы. По умолчанию: `0` (статус текущего пользователя). |

### Результат

Возвращает `1` в случае успешного обновления статуса.

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `5` | `User authorization failed: no access_token passed.` — Пользователь не авторизован. |
| `15` | `Access denied` — Нет прав администратора на изменение описания указанного сообщества. |

### Пример запроса
```http
POST /method/status.set HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

text=Пишу%20код&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": 1
}
```
