# status.get

Возвращает текущий статус пользователя (включая транслируемую аудиозапись, если играет музыка в статусе) или описание сообщества.

### Авторизация
Этот метод не требует обязательной авторизации, если указан `user_id` или `group_id`. При вызове без параметров возвращает статус текущего авторизованного пользователя.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `user_id` | integer | Идентификатор пользователя (положительное число) или сообщества (отрицательное число). По умолчанию: ID текущего пользователя. |
| `group_id` | integer | Идентификатор сообщества, статус (описание) которого необходимо получить. |

### Результат

Возвращает объект с полями:
| Поле | Тип | Описание |
| --- | --- | --- |
| `text` | string | Текст статуса пользователя или описание сообщества. |
| `audio` | object | Объект аудиотрека, транслируемого в статус (если музыка транслируется). |

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `5` | `User authorization failed: no access_token passed.` — Пользователь не авторизован при вызове без параметров. |
| `15` | `Access denied` / `Invalid user` — Пользователь или сообщество не найдено, удалено или доступ закрыт настройками приватности. |

### Пример запроса
```http
POST /method/status.get HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

user_id=1&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": {
        "text": "Всем отличного дня!",
        "audio": {
            "id": 10,
            "owner_id": 1,
            "artist": "Виктор Цой",
            "title": "Группа крови",
            "duration": 285,
            "url": "https://openvk.instance/audio/1_10.mp3"
        }
    }
}
```
