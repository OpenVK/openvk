# friends.getRequests

Возвращает список входящих или исходящих заявок на добавление в друзья для текущего пользователя.

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`).

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `out` | integer | `1` — возвращать исходящие заявки (подписки текущего пользователя), `0` — возвращать входящие заявки (подписчики текущего пользователя). По умолчанию: `0`. |
| `fields` | string | Список дополнительных полей профилей пользователей через запятую (например, `sex,bdate,city,country,photo_50`). |
| `offset` | integer | Смещение относительно начала списка заявок. По умолчанию: `0`. |
| `count` | integer | Количество заявок, которое необходимо вернуть (значение должно быть строго меньше `1000`). По умолчанию: `100`. |
| `extended` | integer | Флаг расширенного формата (для совместимости). По умолчанию: `0`. |
| `suggested` | integer | `1` — возвращать рекомендуемые заявки (в текущей версии возвращает пустой список), `0` — обычные заявки. По умолчанию: `0`. |
| `need_messages` | integer | Для API версии ниже 5.0: `1` — возвращать текст сообщения в заявке, `0` — не возвращать. По умолчанию: `0`. |
| `need_mutual` | integer | Для API версии ниже 5.0: `1` — возвращать объект со списком общих друзей `mutual`, `0` — не возвращать. По умолчанию: `0`. |

### Результат

В API версии 5.0 и выше возвращает объект с полями:
* `count` (integer) — общее число подписчиков / заявок;
* `items` (array) — массив объектов пользователей [User](/dev/models/user), содержащих дополнительное поле `user_id`.

В API версии ниже 5.0 возвращается массив объектов заявок вида:
* `uid` (integer) — идентификатор пользователя;
* `user_id` (integer) — идентификатор пользователя;
* `message` (string, опционально) — текст прикрепленного сообщения (при `need_messages=1`);
* `mutual` (object, опционально) — объект со списком общих друзей (при `need_mutual=1`).

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `5` | `User authorization failed: no access_token passed.` — Пользователь не авторизован. |
| `100` | `One of the required parameters was not passed or is invalid.` — Значение параметра `count` превышает допустимый лимит (1000). |

### Пример запроса
```http
POST /method/friends.getRequests HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

out=0&count=20&fields=sex,bdate&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": {
        "count": 1,
        "items": [
            {
                "id": 15,
                "user_id": 15,
                "first_name": "Иван",
                "last_name": "Смирнов",
                "sex": 2,
                "bdate": "20.4.1998"
            }
        ]
    }
}
```
