# friends.getOnline

Возвращает список идентификаторов друзей пользователя, которые в данный момент находятся на сайте (онлайн).

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`).

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `user_id` | integer | Идентификатор пользователя, для которого необходимо получить список друзей онлайн. Если не указан, используется ID текущего пользователя. По умолчанию: `0`. |
| `online_mobile` | integer | Флаг возврата информации об использовании мобильных клиентов (для совместимости). По умолчанию: `0`. |

### Результат

Возвращает массив числовых идентификаторов пользователей (`array of integers`), находящихся в сети.

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `5` | `User authorization failed: no access_token passed.` — Пользователь не авторизован. |
| `15` | `Access denied: this user chose to hide his friends.` — Пользователь скрыл список друзей настройками приватности. |
| `100` | `Invalid user` — Пользователь не найден или был удален/заблокирован. |

### Пример запроса
```http
POST /method/friends.getOnline HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

user_id=1&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": [
        2,
        5,
        18
    ]
}
```
