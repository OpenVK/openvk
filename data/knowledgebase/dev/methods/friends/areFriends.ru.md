# friends.areFriends

Возвращает информацию о статусе отношений (дружбы) текущего пользователя с указанными пользователями.

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`).

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `user_ids` | string | **Обязательный параметр**. Список идентификаторов пользователей через запятую (например, `1,2,3`). |

### Результат

Возвращает массив объектов, каждый из которых содержит:
* `user_id` (integer) — идентификатор пользователя;
* `friend_status` (integer) — статус дружбы:
  * `0` — не является другом, нет активных заявок;
  * `1` — отправлена исходящая заявка (текущий пользователь подписан на него);
  * `2` — имеется входящая заявка (пользователь подписан на текущего пользователя);
  * `3` — пользователи являются взаимными друзьями.

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `5` | `User authorization failed: no access_token passed.` — Пользователь не авторизован. |

### Пример запроса
```http
POST /method/friends.areFriends HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

user_ids=2,3,4&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": [
        {
            "user_id": 2,
            "friend_status": 3
        },
        {
            "user_id": 3,
            "friend_status": 1
        },
        {
            "user_id": 4,
            "friend_status": 0
        }
    ]
}
```
