# friends.search

Осуществляет поиск по списку друзей пользователя по имени или фамилии.

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`).

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `q` | string | **Обязательный параметр**. Строка поискового запроса (подстрока имени или фамилии). |
| `user_id` | integer | Идентификатор пользователя, по списку друзей которого осуществляется поиск. Если не указан, используется ID текущего пользователя. По умолчанию: `0`. |
| `fields` | string | Список дополнительных полей профилей пользователей через запятую (например, `sex,bdate,city,country,photo_50`). Если параметр указан, метод возвращает массив объектов пользователей, иначе — массив числовых ID. |
| `offset` | integer | Смещение относительно начала найденных результатов. По умолчанию: `0`. |
| `count` | integer | Количество возвращаемых результатов. По умолчанию: `100`. |

### Результат

Возвращает объект с полями:
* `count` (integer) — общее количество найденных друзей;
* `items` (array) — массив числовых идентификаторов друзей либо массив объектов пользователей [User](/dev/models/user) (если передан параметр `fields`).

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `5` | `User authorization failed: no access_token passed.` — Пользователь не авторизован. |
| `15` | `Access denied: this user chose to hide his friends.` — Пользователь скрыл список друзей настройками приватности. |
| `100` | `Invalid user` — Пользователь не найден или был удален/заблокирован. |

### Пример запроса
```http
POST /method/friends.search HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

q=Иван&fields=sex,bdate&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": {
        "count": 1,
        "items": [
            {
                "id": 15,
                "first_name": "Иван",
                "last_name": "Смирнов",
                "sex": 2,
                "bdate": "20.4.1998"
            }
        ]
    }
}
```
