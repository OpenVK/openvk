# friends.get

Возвращает список идентификаторов друзей пользователя или расширенную информацию о них.

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`).

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `user_id` | integer | Идентификатор пользователя, для которого необходимо получить список друзей. Если не указан, используется ID текущего пользователя. По умолчанию: `0`. |
| `fields` | string | Список дополнительных полей профилей пользователей через запятую (например, `sex,bdate,city,country,photo_50`). Если параметр указан, метод возвращает массив объектов пользователей, иначе — массив числовых ID. |
| `offset` | integer | Смещение относительно начала списка друзей. По умолчанию: `0`. |
| `count` | integer | Количество друзей, которое необходимо вернуть. По умолчанию: `100`. |

### Результат

В API версии 5.0 и выше возвращает объект с полями:
* `count` (integer) — общее количество друзей пользователя;
* `items` (array) — массив числовых идентификаторов друзей (если параметр `fields` не передан) либо массив объектов пользователей [User](/dev/models/user) (если параметр `fields` указан).

В API версии ниже 5.0 возвращается непосредственно массив идентификаторов друзей либо массив объектов пользователей.

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `5` | `User authorization failed: no access_token passed.` — Пользователь не авторизован. |
| `15` | `Access denied: this user chose to hide his friends.` — Пользователь скрыл список друзей настройками приватности. |
| `100` | `Invalid user` — Пользователь не найден или был удален/заблокирован. |

### Пример запроса
```http
POST /method/friends.get HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

user_id=1&count=2&fields=sex,bdate&access_token=YOUR_ACCESS_TOKEN&v=5.138
```
