# friends.add

Отправляет заявку на добавление в друзья или одобряет входящую заявку от указанного пользователя.

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`) с правами доступа `friends`.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `user_id` | integer | **Обязательный параметр**. Идентификатор пользователя, которому отправляется заявка или чья заявка принимается. |

### Результат

Возвращает числовой статус выполнения операции (`integer`):
* `1` — заявка на добавление в друзья успешно отправлена (пользователь подписался на профиль);
* `2` — входящая заявка одобрена (пользователи стали взаимными друзьями) либо пользователи уже являются друзьями.

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `5` | `User authorization failed: no access_token passed.` — Пользователь не авторизован. |
| `9` | `Flood control: action too fast or too frequent.` — Превышен лимит на частоту отправки исходящих заявок в друзья. |
| `174` | `Cannot add user himself as friend` — Попытка добавить в друзья самого себя. |
| `177` | `Cannot add this user to friends as user not found` — Пользователь с указанным идентификатором не найден. |

### Пример запроса
```http
POST /method/friends.add HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

user_id=2&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": 1
}
```
