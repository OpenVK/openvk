# utils.resolveOffset

Вычисляет точное смещение (`offset`) для постраничной навигации, необходимое для перехода к странице со списком, на которой находится целевой объект (запись на стене, фотография в альбоме или видеозапись).

### Авторизация
Для вызова этого метода необходим токен пользователя.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `owner_id` | integer | **Обязательный параметр.** Идентификатор владельца объекта (положительное число — пользователь, отрицательное — сообщество). |
| `id` | integer | **Обязательный параметр.** Идентификатор целевого объекта (виртуальный ID записи, фотографии или видеозаписи). |
| `id2` | integer | Вторичный идентификатор контейнера (например, идентификатор альбома для `photos.get`). |
| `method` | string | Метод API, для которого рассчитывается смещение: `"wall.get"`, `"photos.get"` или `"video.get"`. По умолчанию: `"wall.get"`. |
| `perPage` | integer | Количество элементов на одной странице списка. По умолчанию: `10`. |
| `rev` | boolean | Порядок сортировки (актуально для фотографий в альбомах): `1` — обратный, `0` — прямой. По умолчанию: `0`. |

### Результат

Возвращает целое число (`integer`) — вычисленное значение смещения `offset`, кратное размеру страницы (`perPage`).

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `100` | `One of the parameters specified was missing or invalid` — не указан или некорректен параметр `perPage` или объект не найден. |
| `-5` | `Unknown entity` — передан неподдерживаемый метод в параметре `method`. |
| `-9` | `Missing relation` — объект отсутствует в указанном альбоме. |

### Пример запроса
```http
POST /method/utils.resolveOffset HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

owner_id=1&id=42&method=wall.get&perPage=10&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": 40
}
```
