# apps.getMiniAppsCatalog

Возвращает каталог мини-приложений для мобильных и веб-клиентов.

> **Примечание (заглушка совместимости):** Каталог мини-приложений в OpenVK не реализован. Метод возвращает пустой объект каталога (`{"count": 0, "items": [], "apps": [], "profiles": [], "groups": []}`).

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`).

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `limit` | integer | Количество элементов для возврата. По умолчанию: `0`. |
| `start_from` | string | Идентификатор смещения для постраничной навигации. |
| `ref` | string | Источник перехода / реферер. |
| `section_id` | integer | Идентификатор раздела каталога. |
| `fields` | string | Список дополнительных полей профилей или сообществ через запятую. |

### Результат
Возвращает объект с данными каталога:

| Поле | Тип | Описание |
| --- | --- | --- |
| `count` | integer | Общее количество мини-приложений (`0`). |
| `items` | array | Список элементов каталога (`[]`). |
| `apps` | array | Список объектов приложений (`[]`). |
| `profiles` | array | Профили пользователей (`[]`). |
| `groups` | array | Сообщества (`[]`). |

### Пример запроса
```http
POST /method/apps.getMiniAppsCatalog HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

limit=10&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": {
        "count": 0,
        "items": [],
        "apps": [],
        "profiles": [],
        "groups": []
    }
}
```
