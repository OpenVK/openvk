# messages.send

Отправляет сообщение пользователю, сообществу или в групповую беседу (чат). Поддерживает отправку текста, медиавложений, стикеров, пересылку и цитирование сообщений, а также географические координаты.

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`).

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `peer_id` | integer | Идентификатор назначения: ID пользователя, ID сообщества со знаком минус (`-id`), или `2000000000 + chat_id` для групповой беседы. |
| `user_id` | integer | Идентификатор пользователя при отправке личного сообщения. |
| `chat_id` | integer | Идентификатор беседы (число `1...N` без смещения 2000000000). |
| `domain` | string | Короткое имя (screen_name) пользователя или сообщества. |
| `message` | string | Текст отправляемого сообщения. |
| `attachment` | string | Список вложений через запятую в формате `<тип><владелец>_<id>` (например, `photo1_456239017,doc1_123`). |
| `sticker_id` | integer | Идентификатор отправляемого стикера. |
| `random_id` | integer | Уникальный числовой идентификатор на стороне клиента (или `guid`), предотвращающий дублирование при повторной отправке. |
| `reply_to` | integer | Идентификатор сообщения, на которое создается ответ (цитата). |
| `forward_messages` | string | Список идентификаторов пересылаемых сообщений через запятую. |
| `forward` | string | JSON-объект с параметрами пересылки (например, `{"conversation_message_ids": [1, 2], "is_reply": true}`). |
| `lat` | float | Географическая широта. |
| `long` | float | Географическая долгота. |
| `unnoticed` | integer | `1` — не обновлять онлайн-статус отправителя, `0` — обновлять. По умолчанию: `0`. |

> **Примечание:** Обязательно должен быть передан хотя бы один адрес назначения (`peer_id`, `user_id`, `chat_id` или `domain`) и хотя бы один элемент содержимого (`message`, `attachment`, `sticker_id` или `forward_messages`).

### Результат

Возвращает идентификатор отправленного сообщения (`integer`).

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `5` | `User authorization failed: no access_token passed.` — Пользователь не авторизован. |
| `100` | `One of the parameters specified was missing or invalid: receiver not specified` — Не указан получатель или содержимое сообщения. |
| `15` | `Access denied` — Доступ к отправке сообщений ограничен. |
| `900` | `Can't send messages for users from blacklist` — Пользователь находится в черном списке получателя. |
| `902` | `Can't send messages to this user due to privacy settings` — Пользователь запретил получение сообщений настройками приватности. |

### Пример запроса
```http
POST /method/messages.send HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

peer_id=2000000001&message=Привет+всем!&random_id=18492048&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": 4512
}
```
