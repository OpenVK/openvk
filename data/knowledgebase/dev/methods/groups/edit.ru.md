# groups.edit

Редактирует основные данные и настройки сообщества.

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`) с правами администратора сообщества.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `group_id` | integer | **Обязательный параметр**. Идентификатор редактируемого сообщества. |
| `title` | string | Название сообщества. |
| `description` | string | Текст описания сообщества. |
| `screen_name` | string | Короткий буквенный адрес сообщества (например, `my_club`). |
| `website` | string | Адрес веб-сайта сообщества. |
| `wall` | integer | Режим стены сообщества (`0` — выключена, `1` — открытая, `2` — ограниченная, `3` — закрытая, `-1` — без изменений). По умолчанию: `-1`. |
| `topics` | integer | Доступность создания тем в обсуждениях: `1` — создавать темы могут все участники, `0` — только руководители. |
| `adminlist` | integer | `1` — отображать блок списка руководителей, `0` — скрывать. |
| `topicsAboveWall` | integer | `1` — отображать блок обсуждений над стеной, `0` — под стеной. |
| `hideFromGlobalFeed` | integer | `1` — скрывать записи сообщества из глобальной ленты новостей, `0` — показывать. |
| `audio` | integer | `1` — разрешить всем участникам загрузку аудиозаписей, `0` — только администраторам. |

### Результат

Возвращает `1` в случае успешного сохранения настроек.

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `5` | `User authorization failed: no access_token passed.` — Пользователь не авторизован. |
| `15` | `Access denied` — Пользователь не является администратором данного сообщества. |
| `50` | `Invalid wall value` — Передано некорректное значение режима стены. |
| `103` | `Invalid screen_name` — Указанный короткий адрес уже занят или содержит недопустимые символы. |

### Пример запроса
```http
POST /method/groups.edit HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

group_id=1&title=Обновленное+название&wall=1&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": 1
}
```
