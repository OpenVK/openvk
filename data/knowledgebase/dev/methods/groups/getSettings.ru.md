# groups.getSettings

Возвращает текущие настройки и доступность разделов сообщества.

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`) с правами администратора сообщества.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `group_id` | integer | **Обязательный параметр**. Идентификатор сообщества. |

### Результат

Возвращает объект с настройками сообщества:
| Поле | Тип | Описание |
| --- | --- | --- |
| `title` | string | Название сообщества. |
| `description` | string | Описание сообщества. |
| `address` | string | Короткий буквенный адрес сообщества. |
| `wall` | integer | Режим стены сообщества (`0` — выключена, `1` — открытая, `2` — ограниченная, `3` — закрытая). |
| `photos` | integer | Состояние раздела фотографий (`1` — включен). |
| `video` | integer | Состояние раздела видеозаписей (`0` — выключен). |
| `audio` | integer | Доступность загрузки аудиозаписей участниками (`1` — разрешено, `0` — запрещено). |
| `docs` | integer | Состояние раздела документов (`1` — включен). |
| `topics` | integer | Доступность создания тем в обсуждениях (`1` — всем участникам, `0` — только администраторам). |
| `website` | string | Адрес веб-сайта сообщества. |

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `5` | `User authorization failed: no access_token passed.` — Пользователь не авторизован. |
| `15` | `Access denied` — Пользователь не является администратором данного сообщества. |

### Пример запроса
```http
POST /method/groups.getSettings HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

group_id=1&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": {
        "title": "Официальная группа OpenVK",
        "description": "Сообщество разработчиков",
        "address": "openvk",
        "wall": 1,
        "photos": 1,
        "video": 0,
        "audio": 1,
        "docs": 1,
        "topics": 1,
        "website": "https://openvk.instance"
    }
}
```
