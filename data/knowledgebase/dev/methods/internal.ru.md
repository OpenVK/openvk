# Методы секции internal

Секция **internal** содержит служебные и внутренние методы API, используемые старыми версиями официальных клиентов или для диагностики сервера.

### Список методов
* **[internal.getNotifications](/dev/methods/internal/getNotifications)** — возвращает системные уведомления (MOTD) для старых мобильных клиентов VK 2.x (в настоящее время возвращает пустой список-заглушку).
* **[internal.giveMeException](/dev/methods/internal/giveMeException)** — выбрасывает тестовое исключение для проверки перехвата ошибок сервера.
