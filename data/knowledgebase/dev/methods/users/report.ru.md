# users.report

Отправляет жалобу модераторам платформы на профиль пользователя.

### Авторизация
Для вызова этого метода необходим токен пользователя.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `user_id` | integer | **Обязательный параметр.** Идентификатор пользователя, на которого отправляется жалоба. |
| `type` | string | Причина жалобы: `"spam"` (спам), `"insult"` (оскорбительное поведение), `"advertisement"` (несанкционированная реклама). По умолчанию: `"spam"`. |
| `comment` | string | Дополнительный комментарий или подробное описание нарушения. |

### Результат

Возвращает `1` при успешной отправке жалобы.

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `12` | `Can't report yourself.` — невозможно отправить жалобу на собственный профиль. |

### Пример запроса
```http
POST /method/users.report HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

user_id=2&type=spam&comment=Рассылка+нежелательных+сообщений&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": 1
}
```
