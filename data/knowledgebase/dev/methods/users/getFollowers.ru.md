# users.getFollowers

Возвращает список идентификаторов или расширенных профилей подписчиков указанного пользователя.

### Авторизация
Для вызова этого метода необходим токен пользователя.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `user_id` | integer | **Обязательный параметр.** Идентификатор пользователя, список подписчиков которого необходимо получить. |
| `fields` | string | Список дополнительных полей профиля через запятую. Если указан, вместо идентификаторов возвращаются полные объекты пользователей. |
| `offset` | integer | Смещение относительно начала списка. По умолчанию: `0`. |
| `count` | integer | Количество возвращаемых записей. По умолчанию: `100`. |

### Результат

Возвращает объект со следующими полями:

| Поле | Тип | Описание |
| --- | --- | --- |
| `count` | integer | Общее количество подписчиков пользователя. |
| `items` | array | Массив числовых идентификаторов пользователей (или массив объектов профилей, если передан параметр `fields`). |

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `14` | `Invalid user` — пользователь не найден или удален. |
| `15` | `Access denied` — доступ к списку подписчиков ограничен настройками приватности. |

### Пример запроса
```http
POST /method/users.getFollowers HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

user_id=1&count=2&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": {
        "count": 12,
        "items": [
            2,
            3
        ]
    }
}
```
