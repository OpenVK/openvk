# users.search

Возвращает список пользователей в соответствии с заданным критерием поиска.

### Авторизация
Для вызова этого метода требуется авторизация пользователя.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `q` | string | Строка поискового запроса (имя или фамилия пользователя). |
| `fields` | string | Список дополнительных полей профиля через запятую. |
| `sex` | integer | Пол: `1` — женщина, `2` — мужчина, `0` — любой. По умолчанию `0`. |
| `status` | integer | Семейное положение (код статуса отношений). |
| `city` | string | Название города. |
| `hometown` | string | Название родного города. |
| `online` | integer | `1` — искать только пользователей онлайн. По умолчанию `0`. |
| `offset` | integer | Смещение относительно начала списка. По умолчанию `0`. |
| `count` | integer | Количество возвращаемых пользователей. По умолчанию `100`, максимальное значение `100`. |

### Результат
Возвращает объект, содержащий общее количество найденных пользователей в поле `count` и массив объектов пользователей в поле `items`.

### Пример ответа

```json
{
    "response": {
        "count": 1,
        "items": [
            {
                "id": 1,
                "first_name": "Павел",
                "last_name": "Дуров",
                "screen_name": "durov"
            }
        ]
    }
}
```
