# users.get

Возвращает расширенную информацию о пользователях.

### Авторизация
Метод доступен без авторизации.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `user_ids` | string | Идентификаторы пользователей или их короткие имена (`screen_name`), перечисленные через запятую. По умолчанию идентификатор текущего пользователя. |
| `fields` | string | Список дополнительных полей профиля, которые необходимо вернуть, перечисленные через запятую (например: `photo_200`, `sex`, `bdate`, `city`, `country`, `status`, `online`, `verified`). |
| `name_case` | string | Падеж для склонения имени и фамилии пользователя: `nom` — именительный (по умолчанию), `gen` — родительный, `dat` — дательный, `acc` — винительный, `ins` — творительный, `abl` — предложный. |

### Результат
Возвращает массив объектов пользователей. Каждый базовый объект пользователя содержит поля:
* `id` — идентификатор пользователя;
* `first_name` — имя;
* `last_name` — фамилия.

### Пример ответа

```json
{
    "response": [
        {
            "id": 1,
            "first_name": "Павел",
            "last_name": "Дуров",
            "screen_name": "durov",
            "photo_200": "https://openvk.instance/assets/packages/static/openvk/img/camera_200.png",
            "online": 1
        }
    ]
}
```
