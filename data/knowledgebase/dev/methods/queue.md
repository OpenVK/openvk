# queue Methods

The **queue** section provides methods for subscribing to real-time event queues via OpenVK's internal LongPoll queue broker.

## Method List

* **[queue.subscribe](/dev/methods/queue/subscribe)** — subscribes the client to one or more event queues and returns queue server endpoints with access keys.
* **[queue.unsubscribe](/dev/methods/queue/unsubscribe)** — unsubscribes the client from event queues.
