# Методы секции friends

Секция **friends** содержит методы для работы со списком друзей пользователя, поиском по друзьям, управлением заявками в друзья (входящими и исходящими), получением информации об общих и онлайн-друзьях, а также проверкой статуса отношений между пользователями.

### Получение и поиск друзей
* **[friends.get](/dev/methods/friends/get)** — возвращает список идентификаторов друзей пользователя или расширенные объекты их профилей.
* **[friends.getOnline](/dev/methods/friends/getOnline)** — возвращает список идентификаторов друзей пользователя, которые сейчас находятся на сайте (онлайн).
* **[friends.getMutual](/dev/methods/friends/getMutual)** — возвращает список общих друзей между текущим (или указанным) пользователем и другими пользователями.
* **[friends.search](/dev/methods/friends/search)** — осуществляет поиск по списку друзей пользователя по подстроке имени или фамилии.
* **[friends.getSuggestions](/dev/methods/friends/getSuggestions)** — возвращает список рекомендуемых друзей (заглушка совместимости).

### Управление заявками и дружбой
* **[friends.getRequests](/dev/methods/friends/getRequests)** — возвращает список входящих или исходящих заявок на добавление в друзья.
* **[friends.areFriends](/dev/methods/friends/areFriends)** — возвращает статус отношений (дружба, входящая заявка, исходящая заявка, нет отношений) с переданным списком пользователей.
* **[friends.add](/dev/methods/friends/add)** — отправляет заявку на добавление в друзья или одобряет входящую заявку от пользователя.
* **[friends.delete](/dev/methods/friends/delete)** — удаляет пользователя из списка друзей или отклоняет входящую заявку.

### Списки друзей (заглушки)
* **[friends.getLists](/dev/methods/friends/getLists)** — возвращает список списков (меток) друзей пользователя.
* **[friends.edit](/dev/methods/friends/edit)** — редактирует привязку пользователя к спискам друзей.
* **[friends.editList](/dev/methods/friends/editList)** — редактирует название существующего списка друзей.
* **[friends.deleteList](/dev/methods/friends/deleteList)** — удаляет список друзей.
