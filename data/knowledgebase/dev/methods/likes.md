# likes methods

The **likes** section provides methods for interacting with "Like" reactions on posts, comments, photos, videos, and notes, including adding or removing likes, checking like status, and retrieving lists of users who liked an item.

### Method List
* **[likes.add](/dev/methods/likes/add)** — adds a "Like" reaction to the specified object.
* **[likes.delete](/dev/methods/likes/delete)** — removes a "Like" reaction from the specified object.
* **[likes.isLiked](/dev/methods/likes/isLiked)** — checks whether the specified object is in the user's liked list.
* **[likes.getList](/dev/methods/likes/getList)** — returns a list of IDs or user profiles of users who liked the specified object.
