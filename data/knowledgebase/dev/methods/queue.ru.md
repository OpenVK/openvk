# Методы queue

Секция **queue** содержит методы для подписки на очереди событий в реальном времени через внутренний LongPoll-сервис очередей OpenVK.

## Список методов

* **[queue.subscribe](/dev/methods/queue/subscribe)** — оформляет подписку на одну или несколько очередей событий и возвращает URL сервера очередей с ключами доступа.
* **[queue.unsubscribe](/dev/methods/queue/unsubscribe)** — отписывает клиента от очередей событий.
