# notes.edit

Редактирует существующую заметку текущего пользователя.

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`). Метод выполняет действие записи.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `note_id` | integer / string | **Обязательный параметр**. Идентификатор заметки. |
| `title` | string | Новый заголовок заметки. |
| `text` | string | Новый текст заметки. |
| `privacy` | integer | Уровень приватности просмотра (устаревший параметр). |
| `comment_privacy` | integer | Уровень приватности комментирования (устаревший параметр). |
| `privacy_view` | string | Настройки приватности просмотра. |
| `privacy_comment` | string | Настройки приватности комментирования. |

### Результат

Возвращает `1` в случае успешного сохранения изменений.

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `5` | `User authorization failed: no access_token passed.` — Пользователь не авторизован. |
| `15` | `Access denied` — Заметка не найдена, удалена или принадлежит другому пользователю. |

### Пример запроса
```http
POST /method/notes.edit HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

note_id=1&title=Обновленный%20заголовок&text=Обновленный%20текст&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": 1
}
```
