# notes.get

Возвращает список заметок указанного пользователя с учетом настроек приватности.

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`).

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `user_id` | integer | **Обязательный параметр**. Идентификатор пользователя, заметки которого требуется получить. |
| `note_ids` | string | Идентификаторы конкретных заметок, перечисленные через запятую. |
| `offset` | integer | Смещение относительно начала списка. По умолчанию: `0`. |
| `count` | integer | Количество возвращаемых заметок. По умолчанию: `10`. |
| `sort` | integer | Порядок сортировки: `0` — по возрастанию даты создания (ASC), `1` — по убыванию даты создания (DESC). По умолчанию: `0`. |

### Результат

В API версии 5.0 и выше возвращает объект со следующими полями:
* `count` (integer) — общее количество заметок пользователя;
* `items` (array) — массив объектов заметок (`id`, `owner_id`, `title`, `text`, `date`, `comments`, `read_comments`, `view_url`).

В устаревших версиях API (до версии 5.0) возвращает массив, где первым элементом является общее число заметок (`count`), а последующими — объекты заметок.

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `5` | `User authorization failed: no access_token passed.` — Пользователь не авторизован. |
| `15` | `Access denied` — Пользователь не найден, удален или доступ к его заметкам ограничен настройками приватности. |

### Пример запроса
```http
POST /method/notes.get HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

user_id=1&count=5&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": {
        "count": 1,
        "items": [
            {
                "id": 1,
                "owner_id": 1,
                "title": "Моя первая заметка",
                "text": "Привет, мир!",
                "date": 1700000000,
                "comments": 0,
                "read_comments": 0,
                "view_url": "/notes1_1"
            }
        ]
    }
}
```
