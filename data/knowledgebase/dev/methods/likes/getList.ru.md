# likes.getList

Возвращает список идентификаторов пользователей или расширенную информацию о пользователях, поставивших отметку «Мне нравится» к указанному объекту (записи, комментарию, фотографии или видеозаписи).

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`).

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `type` | string | **Обязательный параметр**. Тип объекта: `"post"` (запись на стене), `"comment"` (комментарий), `"photo"` (фотография), `"video"` (видеозапись). |
| `owner_id` | integer | **Обязательный параметр**. Идентификатор владельца объекта (пользователя или сообщества). |
| `item_id` | integer | **Обязательный параметр**. Идентификатор самого объекта. |
| `extended` | boolean | `1` (`true`) — возвращать расширенные профили пользователей (`id`, `first_name`, `last_name`, `photo_50`, `photo_100`), `0` (`false`) — возвращать только идентификаторы пользователей. По умолчанию: `0`. |
| `offset` | integer | Смещение относительно начала списка пользователей. По умолчанию: `0`. |
| `count` | integer | Количество возвращаемых пользователей. По умолчанию: `10`. |
| `skip_own` | boolean | `1` (`true`) — не включать текущего пользователя в результат. По умолчанию: `0`. |

### Результат

В API версии 5.0 и выше возвращает объект со следующими полями:
* `count` (integer) — общее количество отметок «Мне нравится» у объекта;
* `items` (array) — массив идентификаторов пользователей (числа) или профилей пользователей (при `extended=1`).

В устаревших версиях API (до версии 5.0) возвращает массив, первым элементом которого является число отметок (`count`), а последующими — идентификаторы или объекты пользователей.

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `5` | `User authorization failed: no access_token passed.` — Пользователь не авторизован. |
| `58` | `Invalid type` — Указан некорректный тип объекта. |
| `56` | `Invalid postable` — Объект не найден или был удален. |
| `665` | `Access to postable denied` — Доступ к объекту ограничен настройками приватности. |

### Пример запроса
```http
POST /method/likes.getList HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

type=post&owner_id=1&item_id=42&extended=0&count=2&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": {
        "count": 2,
        "items": [
            1,
            2
        ]
    }
}
```
