# docs.get

Возвращает список документов текущего пользователя или сообщества.

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`) с правами доступа `docs`.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `count` | integer | Количество документов, которое необходимо вернуть. По умолчанию: `30`. |
| `offset` | integer | Смещение относительно начала списка документов. По умолчанию: `0`. |
| `type` | integer | Фильтрация по типу документа (`1` — текстовые документы, `2` — архивы, `3` — GIF, `4` — изображения, `5` — аудио, `6` — видео, `7` — книги, `8` — другое, `-1` — все типы). По умолчанию: `-1`. |
| `owner_id` | integer | Идентификатор владельца документов (положительное число — ID текущего пользователя, отрицательное — ID сообщества). Просмотр документов других пользователей через данный метод запрещен. По умолчанию: ID текущего пользователя. |
| `return_tags` | integer | `1` — возвращать массив тегов `tags` для каждого документа, `0` — не возвращать. По умолчанию: `0`. |
| `order` | integer | Порядок сортировки: `0` — по дате добавления (сначала новые), `1` — по названию в алфавитном порядке, `2` — по размеру файла (по убыванию). По умолчанию: `0`. |

### Результат

В API версии 5.0 и выше возвращает объект с полями:
* `count` (integer) — общее число документов;
* `items` (array) — массив объектов документов.

В API версии ниже 5.0 возвращается массив формата `[count, doc1, doc2, ...]`.

Каждый объект документа содержит:

| Поле | Тип | Описание |
| --- | --- | --- |
| `id` | integer | Идентификатор документа. |
| `owner_id` | integer | Идентификатор владельца (виртуальный ID). |
| `true_owner_id` | integer | Реальный идентификатор владельца (если владелец не скрыт, иначе `0`). |
| `title` | string | Название файла. |
| `size` | integer | Размер файла в байтах. |
| `ext` | string | Расширение файла (например, `pdf`, `zip`, `docx`). |
| `url` | string | Прямая ссылка для скачивания документа. |
| `date` | integer | Дата добавления (Unix timestamp). |
| `type` | integer | Числовой тип документа (1..8). |
| `is_hidden` | integer | `1` — владелец документа скрыт, `0` — открыт. |
| `is_licensed` | integer | Лицензирован ли документ. |
| `is_unsafe` | integer | Помечен ли файл как небезопасный. |
| `folder_id` | integer | Папка документа (`0` — личные, `3` — общие). |
| `access_key` | string | Ключ доступа к документу. |
| `can_manage` | boolean | Доступен ли документ для редактирования/удаления текущему пользователю. |
| `preview` | object | Объект с размерами миниатюр (если для файла создано превью, например для GIF или изображений). |
| `tags` | array | Массив строковых тегов (если передан `return_tags=1`). |

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `5` | `User authorization failed: no access_token passed.` — Пользователь не авторизован. |
| `15` | `Access denied` — Попытка запросить документы другого пользователя. |

### Пример запроса
```http
POST /method/docs.get HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

count=2&return_tags=1&access_token=YOUR_ACCESS_TOKEN&v=5.138
```
