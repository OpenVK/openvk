# docs.save

Сохраняет документ после его загрузки на сервер.

> **Примечание:** В текущей версии OpenVK метод возвращает заглушку (`0`).

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`) с правами доступа `docs`.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `file` | string | Ответ сервера загрузки с информацией о файле. **Обязательный параметр.** |
| `title` | string | Название документа. **Обязательный параметр.** |
| `tags` | string | Теги документа через запятую. **Обязательный параметр.** |
| `return_tags` | integer | `1` — возвращать теги в объекте сохраненного документа. По умолчанию: `0`. |

### Результат

В текущей версии возвращает `0`.

### Пример запроса
```http
POST /method/docs.save HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

file=UPLOAD_RESPONSE&title=Отчет.docx&tags=отчет&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": 0
}
```
