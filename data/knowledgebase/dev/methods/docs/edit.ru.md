# docs.edit

Редактирует название, теги, папку и видимость владельца документа.

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`) с правами доступа `docs`.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `owner_id` | integer | Идентификатор владельца документа. **Обязательный параметр.** |
| `doc_id` | integer | Идентификатор документа. **Обязательный параметр.** |
| `title` | string | Новое название документа (до 128 символов). |
| `tags` | string | Список тегов через запятую (до 256 символов). |
| `folder_id` | integer | Идентификатор папки (`0` — личные/приватные, `3` — общие/публичные). |
| `owner_hidden` | integer | `1` — скрыть автора документа, `0` — показывать автора, `-1` — не изменять. По умолчанию: `-1`. |

### Результат

Возвращает `1` в случае успешного сохранения изменений, либо `0` в случае ошибки.

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `5` | `User authorization failed: no access_token passed.` — Пользователь не авторизован. |
| `1150` | `Invalid document id` — Документ не найден или удален. |
| `1152` | `Invalid document title` — Длина названия превышает 128 символов. |
| `1153` | `Access to document is denied` — Нет прав на редактирование документа. |
| `1154` | `Invalid tags` — Длина строки тегов превышает 256 символов. |

### Пример запроса
```http
POST /method/docs.edit HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

owner_id=1&doc_id=45&title=Новое_название.pdf&tags=документы,работа&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": 1
}
```
