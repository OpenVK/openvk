# docs.getTypes

Возвращает список типов документов пользователя или сообщества с количеством документов в каждой категории.

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`).

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `owner_id` | integer | Идентификатор владельца документов (положительное число — текущий пользователь, отрицательное — сообщество). По умолчанию: ID текущего пользователя. |

### Результат

Возвращает объект со следующими полями:
* `count` (integer) — количество доступных категорий;
* `items` (array) — массив объектов категорий, где каждый объект содержит:
  * `type` (integer) — числовой идентификатор типа (`1` — текстовые документы, `2` — архивы, `3` — GIF, `4` — изображения, `5` — аудио, `6` — видео, `7` — книги, `8` — другое);
  * `name` (string) — локализованное название категории;
  * `count` (integer) — количество файлов в данной категории.

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `5` | `User authorization failed: no access_token passed.` — Пользователь не авторизован. |
| `15` | `Access denied` — Попытка запросить типы документов другого пользователя. |

### Пример запроса
```http
POST /method/docs.getTypes HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": {
        "count": 3,
        "items": [
            {
                "type": 1,
                "name": "Текстовые документы",
                "count": 12
            },
            {
                "type": 2,
                "name": "Архивы",
                "count": 4
            },
            {
                "type": 7,
                "name": "Электронные книги",
                "count": 2
            }
        ]
    }
}
```
