# Методы секции gifts

Секция **gifts** содержит методы для работы с подарками: просмотр полученных подарков пользователя, отправка подарков за голоса (монеты), удаление отправленных подарков, а также просмотр каталога категорий и доступных в них подарков.

### Работа с подарками
* **[gifts.get](/dev/methods/gifts/get)** — возвращает список подарков, полученных пользователем.
* **[gifts.send](/dev/methods/gifts/send)** — отправляет подарок указанному пользователю с возможностью прикрепления сообщения и выбора приватности.
* **[gifts.delete](/dev/methods/gifts/delete)** — удаляет отправленный пользователем подарок.

### Каталог подарков
* **[gifts.getCategories](/dev/methods/gifts/getCategories)** — возвращает список категорий каталога подарков платформы.
* **[gifts.getGiftsInCategory](/dev/methods/gifts/getGiftsInCategory)** — возвращает список подарков в выбранной категории каталога с указанием стоимости и доступных бесплатных отправок.
