# gifts.send

Отправляет подарок указанному пользователю за голоса (монеты) с возможностью прикрепления сообщения и выбора уровня приватности.

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`).

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `user_ids` | integer | **Обязательный параметр**. Идентификатор пользователя-получателя подарка. |
| `gift_id` | integer | **Обязательный параметр**. Идентификатор отправляемого подарка из каталога. |
| `message` | string | Текст сопроводительного сообщения к подарку. По умолчанию: пустая строка. |
| `privacy` | integer | Уровень приватности: `0` — имя отправителя видно всем, `1` — имя отправителя скрыто (анонимный подарок). По умолчанию: `0`. |

### Результат

Возвращает объект со статусом отправки:
* При успешной отправке:
  * `success` (integer) — `1`;
  * `user_ids` (integer) — идентификатор получателя;
  * `withdraw_votes` (integer) — списанное количество голосов (монет).
* При нехватке голосов или исчерпании лимита бесплатных отправок:
  * `success` (integer) — `0`;
  * `user_ids` (integer) — идентификатор получателя;
  * `error` (string) — текст ошибки (`"You don't have enough voices."` или `"You don't have any more of these gifts."`).

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `-105` | `Commerce is disabled on this instance` — Система коммерции/голосов отключена на данном инстансе. |
| `5` | `User authorization failed: no access_token passed.` — Пользователь не авторизован. |
| `9` | `Flood control: action too fast or too frequent.` — Слишком частая отправка подарков. |
| `15` | `Access denied` — Доступ к отправке подарка данному пользователю ограничен настройками приватности или пользователь заблокирован. |
| `15` | `Invalid gift` — Подарок с указанным `gift_id` не найден в каталоге. |

### Пример запроса
```http
POST /method/gifts.send HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

user_ids=2&gift_id=101&message=С+праздником!&privacy=0&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": {
        "success": 1,
        "user_ids": 2,
        "withdraw_votes": 1
    }
}
```
