# account.saveProfileInfo

Редактирует базовую информацию профиля текущего пользователя.

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`). Метод проверяет ограничения частоты запросов на запись.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `first_name` | string | Имя пользователя. При смене имени изменения применяются сразу, а в ответе возвращается объект `name_request` со статусом `"success"` для совместимости с клиентами VK. |
| `last_name` | string | Фамилия пользователя. |
| `screen_name` | string | Короткий буквенный адрес страницы (например `durov`). |
| `sex` | integer | Пол: `1` — женский, `2` — мужской. |
| `relation` | integer | Семейное положение: `0` — не указано, `1` — не женат/не замужем, `2` — есть друг/подруга, `3` — помолвлен/помолвлена, `4` — женат/замужем, `5` — всё сложно, `6` — в активном поиске, `7` — влюблен/влюблена, `8` — в гражданском браке. |
| `bdate` | string | Дата рождения (в формате `DD.MM.YYYY` или `YYYY-MM-DD`). |
| `bdate_visibility` | integer | Видимость даты рождения: `1` — показывать полностью, `2` — только месяц и день, `0` — скрыть (в OpenVK сокрытие не поддерживается и вернет ошибку `946`). |
| `home_town` | string | Родной город. |
| `status` | string | Текстовый статус профиля. |
| `telegram` | string | Ссылка на Telegram или никнейм. |

### Результат
Возвращает объект, содержащий:

| Поле | Тип | Описание |
| --- | --- | --- |
| `changed` | integer | `1`, если настройки или данные профиля были успешно обновлены, иначе `0`. |
| `name_request` | object\|null | *(Опционально)* Объект эмуляции заявки на смену имени (`id`, `status`, `first_name`, `last_name`). |

### Возможные ошибки

| Код | Сообщение | Описание |
| --- | --- | --- |
| `100` | `invalid value of bdate.` | Некорректный формат или значение даты рождения. |
| `1260` | `Invalid screen name` | Недопустимый короткий адрес страницы. |
| `946` | `Hiding date of birth is not implemented.` | Попытка скрыть дату рождения (`bdate_visibility = 0`). |

### Пример запроса
```http
POST /method/account.saveProfileInfo HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

status=Работаю+над+OpenVK&screen_name=durov&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": {
        "changed": 1
    }
}
```
