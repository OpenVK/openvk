# account.getContactList

Возвращает список импортированных контактов телефонной книги пользователя.

> **Примечание (заглушка совместимости):** Синхронизация телефонных контактов не реализована. Метод возвращает пустой список (`{"count": 0, "items": []}`) для предотвращения ошибок в официальных клиентах.

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`).

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `offset` | integer | Смещение для постраничной выборки. По умолчанию: `0`. |
| `count` | integer | Количество возвращаемых записей (максимум `100`). По умолчанию: `100`. |
| `fields` | string | Список дополнительных полей профилей через запятую. |

### Результат
Возвращает объект со списком контактов:

| Поле | Тип | Описание |
| --- | --- | --- |
| `count` | integer | Количество записей (`0`). |
| `items` | array | Массив контактов (`[]`). |

### Пример запроса
```http
POST /method/account.getContactList HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": {
        "count": 0,
        "items": []
    }
}
```
