# account.getAppPermissions

Возвращает битовую маску настроек и разрешенных прав доступа текущего приложения.

> **Примечание:** В текущей реализации метод возвращает фиксированное значение `9355263` (маска со всеми правами) для обеспечения полной совместимости со сторонними и официальными клиентами VK.

### Авторизация
Метод доступен без авторизации пользователя.

### Параметры
Метод не принимает параметров.

### Результат
Возвращает целое число — битовую маску прав доступа приложения.

### Пример запроса
```http
POST /method/account.getAppPermissions HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

v=5.138
```

### Пример ответа
```json
{
    "response": 9355263
}
```
