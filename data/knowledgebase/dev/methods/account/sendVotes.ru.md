# account.sendVotes

Передает голоса (монеты) с баланса текущего пользователя другому пользователю.

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`). Метод проверяет ограничения частоты запросов на запись.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `receiver` | integer | Идентификатор пользователя-получателя голосов. **Обязательный параметр.** |
| `value` | integer | Количество передаваемых голосов (минимум `1`). **Обязательный параметр.** |
| `message` | string | Сопроводительное текстовое сообщение (максимум 255 символов). |

### Результат
Возвращает объект, содержащий обновленный баланс:

| Поле | Тип | Описание |
| --- | --- | --- |
| `votes` | integer | Новый остаток голосов на балансе текущего пользователя. |

### Возможные ошибки

| Код | Сообщение | Описание |
| --- | --- | --- |
| `-105` | `Commerce is disabled on this instance` | Коммерция и передача голосов отключены на инстансе. |
| `-248` | `Invalid receiver id` / `Invalid value` | Некорректный ID получателя или количество голосов меньше 1. |
| `-249` | `Message is too long` | Длина сообщения превышает 255 символов. |
| `-250` | `Invalid receiver` | Получатель не найден, удален или недоступен для просмотра. |
| `-251` | `Can't transfer votes to yourself` | Попытка перевести голоса на свой собственный аккаунт. |
| `-252` | `Not enough votes` | Недостаточно голосов на балансе для совершения перевода. |

### Пример запроса
```http
POST /method/account.sendVotes HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

receiver=2&value=10&message=Спасибо!&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": {
        "votes": 90
    }
}
```
