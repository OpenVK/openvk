# account.ban

Добавляет пользователя в черный список текущего пользователя.

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`).

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `owner_id` | integer | Идентификатор пользователя, которого необходимо добавить в черный список. **Обязательный параметр.** |

### Результат
Возвращает `1` в случае успешного добавления в черный список (или если пользователь уже был заблокирован).  
Возвращает `0`, если указанный пользователь не найден или удален.

### Возможные ошибки

| Код | Сообщение | Описание |
| --- | --- | --- |
| `15` | `Access denied: cannot blacklist yourself` | Попытка добавить в черный список самого себя. |
| `-7856` | `Blacklist limit exceeded` | Превышен лимит пользователей в черном списке. |

### Пример запроса
```http
POST /method/account.ban HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

owner_id=2&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": 1
}
```
