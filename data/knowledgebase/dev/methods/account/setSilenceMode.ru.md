# account.setSilenceMode

Отключает звуковые сигналы или Push-уведомления на заданный период времени для определенного диалога или глобально.

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`). Метод проверяет ограничения частоты запросов на запись.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `token` | string | Токен устройства. |
| `time` | integer | Длительность тихого режима в секундах: `-1` — отключить навсегда, `0` — включить уведомления обратно. По умолчанию: `0`. |
| `peer_id` | integer | Идентификатор диалога/беседы. Если `0` или не указан — применяется глобально. По умолчанию: `0`. |
| `sound` | integer | `1` — воспроизводить звук при получении уведомлений, `0` — уведомления без звука. По умолчанию: `1`. |
| `disabled_mentions` | integer | `1` — отключить уведомления при прямых упоминаниях в беседах. По умолчанию: `0`. |
| `disabled_mass_mentions` | integer | `1` — отключить уведомления при массовых упоминаниях (`@all`, `@online`). По умолчанию: `0`. |

### Результат
Возвращает `1` в случае успешной смены настроек.

### Пример запроса
```http
POST /method/account.setSilenceMode HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

peer_id=2000000001&time=3600&sound=0&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": 1
}
```
