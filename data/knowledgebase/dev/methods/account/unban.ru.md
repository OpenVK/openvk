# account.unban

Удаляет пользователя из черного списка текущего пользователя.

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`).

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `owner_id` | integer | Идентификатор пользователя, которого необходимо удалить из черного списка. **Обязательный параметр.** |

### Результат
Возвращает `1` в случае успешного удаления из черного списка (или если пользователь не находился в списке).  
Возвращает `0`, если указанный пользователь не существует.

### Пример запроса
```http
POST /method/account.unban HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

owner_id=2&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": 1
}
```
