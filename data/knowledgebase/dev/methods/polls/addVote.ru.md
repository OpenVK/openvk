# polls.addVote

Отдает голос текущего пользователя за один или несколько вариантов ответа в опросе.

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`) с правами доступа `wall`.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `poll_id` | integer | **Обязательный параметр.** Идентификатор опроса. |
| `answer_ids` | string | Идентификаторы выбранных вариантов ответа через запятую (для опросов с множественным выбором). |
| `answer_id` | string | Идентификатор выбранного варианта ответа (для опросов с одиночным выбором). |
| `owner_id` | integer | Идентификатор владельца опроса. По умолчанию: `0`. |

> **Примечание:** Необходимо передать хотя бы один из параметров: `answer_ids` или `answer_id`.

### Результат

Возвращает:
* `1` — голос успешно учтен;
* `0` — пользователь уже проголосовал ранее или опрос завершен/заблокирован.

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `5` | `User authorization failed: no access_token passed.` — Пользователь не авторизован. |
| `100` | `Required parameter 'answer_ids' or 'answer_id' is missing.` — Не указан вариант ответа. |
| `251` | `Invalid poll id` — Опрос не найден. |

### Пример запроса
```http
POST /method/polls.addVote HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

poll_id=1&answer_id=1&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": 1
}
```
