# gifts Methods

The **gifts** section contains methods for managing gifts: viewing gifts received by a user, sending gifts for votes (coins), deleting sent gifts, and exploring the catalog of gift categories and gifts.

### Managing Gifts
* **[gifts.get](/dev/methods/gifts/get)** — Returns a list of gifts received by a user.
* **[gifts.send](/dev/methods/gifts/send)** — Sends a gift to a specified user with an optional message and privacy level.
* **[gifts.delete](/dev/methods/gifts/delete)** — Deletes a previously sent gift.

### Gift Catalog
* **[gifts.getCategories](/dev/methods/gifts/getCategories)** — Returns the list of gift categories in the catalog.
* **[gifts.getGiftsInCategory](/dev/methods/gifts/getGiftsInCategory)** — Returns gifts available in a specific catalog category with pricing and usage limits.
