# wall.edit

Редактирует существующую запись на стене пользователя или сообщества.

### Авторизация
Для вызова этого метода необходим токен пользователя с правами на редактирование записи.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `owner_id` | integer | **Обязательный параметр.** Идентификатор владельца стены (положительное число — пользователь, отрицательное — сообщество). |
| `post_id` | integer | **Обязательный параметр.** Идентификатор редактируемой записи. |
| `message` | string | Новый текст записи. |
| `attachments` | string | Новый список медиавложений через запятую (или `"remove"` для удаления всех вложений). |
| `copyright` | string | Новая ссылка на первоисточник (или `"remove"` для удаления копирайта). |
| `explicit` | integer | `1` — установить пометку NSFW, `0` — снять пометку. |
| `from_group` | integer | `1` — публиковать от имени сообщества. |
| `signed` | integer | `1` — добавить подпись автора. |

### Результат

Возвращает объект с идентификатором отредактированной записи:

| Поле | Тип | Описание |
| --- | --- | --- |
| `post_id` | integer | Идентификатор отредактированной записи. |

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `7` | `Access to editing denied` — недостаточно прав для редактирования записи. |
| `102` | `Invalid post` — запись не найдена или удалена. |
| `-66` | `Post will be empty, don't saving.` — невозможно сохранить полностью пустую запись без текста и вложений. |

### Пример запроса
```http
POST /method/wall.edit HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

owner_id=1&post_id=42&message=Обновленный+текст+записи&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": {
        "post_id": 42
    }
}
```
