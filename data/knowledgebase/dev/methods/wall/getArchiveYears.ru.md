# wall.getArchiveYears

Возвращает список годов, за которые у пользователя или сообщества имеются записи в архиве.

### Авторизация
Для вызова этого метода необходим токен пользователя. Просматривать архив может только владелец профиля или администратор сообщества.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `owner_id` | integer | **Обязательный параметр.** Идентификатор владельца стены (положительное число — пользователь, отрицательное — сообщество). |

### Результат

Возвращает массив целых чисел (`array of integer`), представляющих года (например, `[2024, 2023, 2022]`), за которые существуют архивные записи на стене.

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `15` | `Access denied` — владелец не найден или у текущего пользователя нет прав на просмотр архива. |

### Пример запроса
```http
POST /method/wall.getArchiveYears HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

owner_id=1&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": [
        2024,
        2023,
        2022
    ]
}
```
