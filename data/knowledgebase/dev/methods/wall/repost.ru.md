# wall.repost

Копирует объект (запись на стене, фотографию или видеозапись) на стену текущего пользователя или указанного сообщества.

### Авторизация
Для вызова этого метода необходим токен пользователя с правом публикации на стене (`wall`).

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `object` | string | **Обязательный параметр.** Идентификатор копируемого объекта в формате `<тип><владелец>_<id>` (например, `wall1_42`, `photo1_12`, `video-5_10`). |
| `message` | string | Сопроводительный текст текущего пользователя к репосту. |
| `attachments` | string | Список дополнительных медиавложений через запятую. |
| `group_id` | integer | Идентификатор сообщества, на стену которого будет опубликован репост (если требуется опубликовать в группу). |
| `as_group` | integer | `1` — опубликовать репост от имени сообщества (при указании `group_id`). |
| `signed` | integer | `1` — добавить подпись автора к репосту от имени сообщества. |

### Результат

Возвращает объект с информацией о созданном репосте:

| Поле | Тип | Описание |
| --- | --- | --- |
| `success` | integer | Всегда `1` при успешном выполнении. |
| `post_id` | integer | Идентификатор созданной записи на стене. |
| `reposts_count` | integer | Общее количество репостов исходного объекта. |
| `likes_count` | integer | Общее количество лайков исходного объекта. |

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `100` | `One of the parameters specified was missing or invalid: object is incorrect` — не передан или некорректно указан `object`. |
| `16` | `Access to group denied` — нет прав на публикацию в указанном сообществе. |

### Пример запроса
```http
POST /method/wall.repost HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

object=wall1_10&message=Рекомендую+к+прочтению!&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": {
        "success": 1,
        "post_id": 43,
        "reposts_count": 2,
        "likes_count": 5
    }
}
```
