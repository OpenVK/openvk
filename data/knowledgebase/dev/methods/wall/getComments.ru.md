# wall.getComments

Возвращает список комментариев к записи на стене.

### Авторизация
Для вызова этого метода необходим токен пользователя.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `owner_id` | integer | **Обязательный параметр.** Идентификатор владельца стены (положительное число — пользователь, отрицательное — сообщество). |
| `post_id` | integer | **Обязательный параметр.** Идентификатор записи на стене. |
| `need_likes` | integer | `1` — возвращать информацию о лайках к комментариям. По умолчанию: `1`. |
| `offset` | integer | Смещение для выборки комментариев. По умолчанию: `0`. |
| `count` | integer | Количество возвращаемых комментариев. По умолчанию: `10`. |
| `sort` | string | Порядок сортировки: `"asc"` — в хронологическом порядке (от старых к новым), `"desc"` — в обратном порядке (от новых к старым). По умолчанию: `"asc"`. |
| `extended` | boolean / integer | `1` — возвращать профили и сообщества авторов (`profiles`, `groups`), `0` — только массив комментариев. По умолчанию: `0`. |
| `fields` | string | Список дополнительных полей профилей через запятую. |

### Результат

Возвращает объект со следующими полями:

| Поле | Тип | Описание |
| --- | --- | --- |
| `count` | integer | Общее количество комментариев к записи. |
| `items` | array | Массив объектов комментариев. |
| `profiles` | array | Профили авторов комментариев (при `extended=1`). |
| `groups` | array | Сообщества авторов комментариев (при `extended=1`). |

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `15` | `Access denied` — запись закрыта настройками приватности. |
| `100` | `One of the parameters specified was missing or invalid` — запись не найдена или удалена. |

### Пример запроса
```http
POST /method/wall.getComments HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

owner_id=1&post_id=10&count=5&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

    "response": {

                }
            }
