# wall.getSubscriptions

Возвращает список сообществ и пользователей, на чьи обновления стены подписан текущий пользователь.

### Авторизация
Для вызова этого метода необходим токен пользователя.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `offset` | integer | Смещение относительно начала списка подписок. По умолчанию: `0`. |
| `count` | integer | Количество возвращаемых подписок. По умолчанию: `20`. |
| `extended` | integer | `1` — возвращать полные объекты сообществ и пользователей, `0` — только идентификаторы. По умолчанию: `0`. |
| `fields` | string | Список дополнительных полей профилей и сообществ через запятую. |

### Результат

Возвращает объект со следующими полями:

| Поле | Тип | Описание |
| --- | --- | --- |
| `count` | integer | Общее количество подписок. |
| `items` | array | Массив объектов или идентификаторов подписок. |

### Пример запроса
```http
POST /method/wall.getSubscriptions HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

count=10&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": {
        "count": 0,
        "items": []
    }
}
```
