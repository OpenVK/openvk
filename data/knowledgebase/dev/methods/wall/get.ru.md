# wall.get

Возвращает список записей со стены пользователя или сообщества в соответствии с заданными параметрами фильтрации и пагинации.

### Авторизация
Для вызова этого метода необходим токен пользователя.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `owner_id` | integer | **Обязательный параметр.** Идентификатор владельца стены (положительное число — пользователь, отрицательное — сообщество). |
| `domain` | string | Короткий адрес пользователя или сообщества. |
| `offset` | integer | Смещение относительно начала списка записей. По умолчанию: `0`. |
| `count` | integer | Количество возвращаемых записей (максимум `100`). По умолчанию: `30`. |
| `extended` | integer | `1` — возвращать информацию о пользователях (`profiles`) и сообществах (`groups`), `0` — только массив записей. По умолчанию: `0`. |
| `filter` | string | Тип записей для выборки: `"all"` — все записи на стене (по умолчанию), `"owner"` — только записи владельца стены, `"others"` — только чужие записи, `"archived"` — архивные записи, `"suggests"` — предложенные записи (для сообществ). |
| `archive_year` | integer | Год для фильтрации при `filter=archived`. |

### Результат

Возвращает объект со следующими полями:

| Поле | Тип | Описание |
| --- | --- | --- |
| `count` | integer | Общее количество записей, удовлетворяющих условиям фильтра. |
| `items` | array | Массив объектов записей на стене. |
| `profiles` | array | Массив профилей авторов записей и вложений (при `extended=1`). |
| `groups` | array | Массив сообществ авторов записей и вложений (при `extended=1`). |

Каждый объект записи содержит идентификатор `id`, `owner_id`, `from_id`, дату `date`, текст `text`, массив вложений `attachments`, информацию о лайках `likes`, комментариях `comments`, репостах `reposts` и флаг закрепления `is_pinned`.

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `15` | `Access denied` — стена закрыта настройками приватности или отключена. |
| `18` | `User was deleted or banned` — пользователь удален или заблокирован. |

### Пример запроса
```http
POST /method/wall.get HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

owner_id=1&count=2&filter=owner&access_token=YOUR_ACCESS_TOKEN&v=5.138
```
