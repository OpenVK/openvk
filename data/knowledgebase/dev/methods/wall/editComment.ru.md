# wall.editComment

Редактирует текст и вложения комментария к записи на стене.

### Авторизация
Для вызова этого метода необходим токен пользователя. Редактировать комментарий может только его автор.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `comment_id` | integer | **Обязательный параметр.** Идентификатор редактируемого комментария. |
| `owner_id` | integer | Идентификатор владельца стены (необязательный). |
| `message` | string | Новый текст комментария. |
| `attachments` | string | Новый список медиавложений через запятую. |

### Результат

Возвращает `1` при успешном редактировании.

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `15` | `Access to editing comment denied` — у пользователя нет прав на редактирование комментария (или комментарий содержит стикер). |
| `102` | `Invalid comment` — комментарий не найден или удален. |

### Пример запроса
```http
POST /method/wall.editComment HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

comment_id=26&message=Исправленный+текст+комментария&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": 1
}
```
