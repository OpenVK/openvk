# wall.pin

Закрепляет запись вверху стены пользователя или сообщества.

### Авторизация
Для вызова этого метода необходим токен пользователя с правами владельца стены или администратора сообщества.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `owner_id` | integer | **Обязательный параметр.** Идентификатор владельца стены (положительное число — пользователь, отрицательное — сообщество). |
| `post_id` | integer | **Обязательный параметр.** Идентификатор закрепляемой записи на стене. |

### Результат

Возвращает `1` при успешном закреплении записи или `0`, если у пользователя нет прав на закрепление.

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `100` | `One of the parameters specified was missing or invalid: post_id is undefined` — запись не найдена или удалена. |

### Пример запроса
```http
POST /method/wall.pin HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

owner_id=1&post_id=42&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": 1
}
```
