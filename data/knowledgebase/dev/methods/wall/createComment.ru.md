# wall.createComment

Создает новый комментарий к записи на стене.

### Авторизация
Для вызова этого метода необходим токен пользователя.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `owner_id` | integer | **Обязательный параметр.** Идентификатор владельца стены (положительное число — пользователь, отрицательное — сообщество). |
| `post_id` | integer | **Обязательный параметр.** Идентификатор записи на стене. |
| `message` | string | Текст комментария. Обязателен, если не прикреплен стикер или медиавложения. |
| `attachments` | string | Список медиавложений через запятую (`photo`, `video`, `audio`, `doc`, `note`). |
| `from_group` | integer | `1` — оставить комментарий от имени сообщества (при наличии прав администратора). |
| `reply_to_comment` | integer | Идентификатор комментария, на который оставляется ответ. |
| `sticker_id` | integer | Идентификатор отправляемого стикера. |

### Результат

Возвращает объект с идентификатором созданного комментария:

| Поле | Тип | Описание |
| --- | --- | --- |
| `comment_id` | integer | Идентификатор созданного комментария (в API версии 5.x). |

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `15` | `Access denied` — запись закрыта для комментирования. |
| `100` | `Invalid post` — запись не найдена или удалена. |
| `100` | `Required parameter 'message' missing.` — не передан текст, вложение или стикер. |

### Пример запроса
```http
POST /method/wall.createComment HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

owner_id=1&post_id=10&message=Спасибо+за+пост!&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": {
        "comment_id": 26,
        "parents_stack": []
    }
}
```
