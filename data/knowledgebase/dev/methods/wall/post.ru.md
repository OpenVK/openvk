# wall.post

Публикует новую запись на стене пользователя или сообщества, либо публикует ранее предложенную запись.

### Авторизация
Для вызова этого метода необходим токен пользователя с правом публикации на стене (`wall`).

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `owner_id` | integer | **Обязательный параметр.** Идентификатор владельца стены (положительное число — пользователь, отрицательное — сообщество). |
| `message` | string | Текст публикуемой записи. |
| `attachments` | string | Список медиавложений через запятую в формате `<тип><владелец>_<id>` (например, `photo1_23,audio1_45`). |
| `from_group` | integer | `1` — опубликовать запись от имени сообщества (доступно администраторам). По умолчанию: `0`. |
| `signed` | integer | `1` — добавить подпись автора к записи от имени сообщества. По умолчанию: `0`. |
| `copyright` | string | Внешняя ссылка на первоисточник записи (копирайт). |
| `post_id` | integer | Идентификатор предложенной записи в сообществе (для ее одобрения и публикации). |
| `explicit` | integer | `1` — пометить запись как содержащую контент 18+ (NSFW). |
| `lat` | float | Географическая широта места публикации. |
| `long` | float | Географическая долгота места публикации. |
| `place_name` | string | Название места или геоточки. |

### Результат

Возвращает объект с идентификатором созданной записи:

| Поле | Тип | Описание |
| --- | --- | --- |
| `post_id` | integer | Числовой идентификатор созданной записи на стене. |

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `15` | `Access denied` — у пользователя нет прав на публикацию на указанной стене. |
| `18` | `User was deleted or banned` — целевой пользователь удален или заблокирован. |

### Пример запроса
```http
POST /method/wall.post HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

owner_id=1&message=Привет,+мир!&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": {
        "post_id": 42
    }
}
```
