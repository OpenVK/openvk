# internal methods

The **internal** section contains service and internal methods used by legacy clients or server diagnostics.

### Method List
* **[internal.getNotifications](/dev/methods/internal/getNotifications)** — returns service/MOTD notifications for legacy VK 2.x mobile clients (currently a stub).
* **[internal.giveMeException](/dev/methods/internal/giveMeException)** — triggers a test runtime exception for verifying server error handling.
