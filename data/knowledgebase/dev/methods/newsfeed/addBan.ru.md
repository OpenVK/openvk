# newsfeed.addBan

Скрывает публикации указанных пользователей или сообществ из ленты новостей текущего пользователя.

### Авторизация
Для вызова этого метода требуется авторизация пользователя (`access_token`). Метод выполняет действие записи.

### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| `user_ids` | string | Идентификаторы пользователей, перечисленные через запятую (положительные числа). |
| `group_ids` | string | Идентификаторы сообществ, перечисленные через запятую (положительные числа). |

> [!NOTE]
> Суммарное количество передаваемых идентификаторов за один запрос не может превышать 10. Общее количество скрытых источников ограничено настройками сервера (по умолчанию до 50).

### Результат

Возвращает `1` в случае успешного скрытия источников, либо `0`, если список переданных идентификаторов пуст.

### Возможные ошибки

| Код | Описание |
| --- | --- |
| `5` | `User authorization failed: no access_token passed.` — Пользователь не авторизован. |
| `-10` | `Limit of 'ids' is 10` — Превышен лимит передаваемых идентификаторов в одном запросе (максимум 10). |
| `-50` | `Ignoring limit exceeded` — Превышен общий лимит скрытых источников новостей. |

### Пример запроса
```http
POST /method/newsfeed.addBan HTTP/1.1
Host: openvk.instance
Content-Type: application/x-www-form-urlencoded

user_ids=5,10&group_ids=2&access_token=YOUR_ACCESS_TOKEN&v=5.138
```

### Пример ответа
```json
{
    "response": 1
}
```
