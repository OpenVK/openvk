# Data Models

This section describes the data object structures returned by OpenVK API methods.

These models are referenced in API responses across various method sections (e.g. `users`, `groups`, `messages`, `wall`, `photos`, `audio`, `video`, `docs`, etc.).

### Available Models
* **[user](/dev/models/user)** — User profile object.
* **[group](/dev/models/group)** — Community object (group, public page, or event).
* **[chat](/dev/models/chat)** — Multi-user chat object (before API v5.80).
* **[conversation](/dev/models/conversation)** — Conversation / dialogue object (API v5.80 and higher).
* **[message](/dev/models/message)** — Direct or group message object.
* **[post](/dev/models/post)** — Wall post object.
* **[comment](/dev/models/comment)** — Comment object (on posts, photos, videos, notes).
* **[photo](/dev/models/photo)** — Photo object and image copies.
* **[audio](/dev/models/audio)** — Audio track object.
* **[video](/dev/models/video)** — Video recording object.
* **[doc](/dev/models/doc)** — Document / file object.
* **[topic](/dev/models/topic)** — Board topic / discussion thread object.
* **[poll](/dev/models/poll)** — Poll / voting object.
* **[note](/dev/models/note)** — Text note object.
* **[album](/dev/models/album)** — Photo album object.
* **[playlist](/dev/models/playlist)** — Audio playlist object.
* **[sticker](/dev/models/sticker)** — Sticker and sticker pack object.
* **[gift](/dev/models/gift)** — Sent gift object.
